# C：从峡谷小营地，一块一块建成前进中的城镇

用户最新要求：出生周围更狭窄，改变主城布局，按区块向矿区逐块扩张。此前“矿段清空后铺浅色地面、在边缘加房屋”的 C 方案废弃。新布局已在本地 C 实现，技术验证见文末记录；真人体验尚待确认。

## 1. 玩家看见的变化

出生在岩壁夹住的小营地，背后是营门，两侧是房屋与真实阻挡的岩壁，眼前就是第一块待开拓的矿地。玩家不会先跑过大圆形空地再接触矿山。

向前采矿的同时即可捐献扩建金币，可踩地贴，也可在当前矿区点击就地捐献。付满的同一帧炸开建设用地内剩余矿柱，随后矿地被接管为新的城镇街区：施工从旧城边缘向外推进，街道接通，新建筑落地，城门移到更前方。原来站不进去的地方，现在能走进去使用新设施。下一块矿地就在新城门外。

一局里明确发生三次“这里原来是矿，现在是我的城”。旧城区留在身后，不被整城搬走；城市的占地和设施数量逐次增加。

## 2. 空间布局

取消 C 的同心圆主城、环形功能地贴与环形扩张。改成沿屏幕上方向前生长的峡谷街区；主街贯通各区块，建筑放在两侧，侧支路承担建造与升级操作。

从屏幕下方向上看：

```
               封印巨龙（独立终局区域）
                         ↑
               高级矿区 / 最后一波战斗
                         ↑
        [区块 3：前哨城关 · 主城 Lv4]
          左：锻造前沿入口    右：采矿前沿入口
                         ↑
        [区块 2：工坊与龙巢 · 主城 Lv3]
          左：采矿工坊        右：免费孵化巢
                         ↑
        [区块 1：居民与锻造街 · 主城 Lv2]
          左：锻造铺          右：住宅 / 物资棚
                         ↑
        [区块 0：出生营地 · 主城 Lv1]
          左：营房            右：仓棚
                  主堡 / 营门在身后
```

这是解锁后的全布局示意，不是出生时已经开放的城市。初始仅区块 0 可进入，其余区块有实际矿体和障碍占据；前方只读到下一块矿墙及少量远景。

### 出生营地

- 建议初始可走范围约宽 10m、深 9m，作为实现起点，须按角色尺寸和手机取景微调。
- 中间主街净宽至少 3m，侧面设施入口能容纳玩家转身；狭窄来自布局，不通过放大角色或强拉镜头伪造。
- 出生金币仍是 **10**，第一张建城地贴费用 **10**，直接可付。
- 初建生成小主堡、营房和仓棚，保持紧凑；不预留旧版大圆广场。
- 第一块矿的可采面距离初建操作位置约 2–4m。首次操作后就能看见下一步目标。
- 镜头回到营地时，两侧边界须同时进入手机画面。C 开场以读懂营地为先，不强制继承 A 的巨龙运镜；巨龙可在后续推进中露出。

## 3. 三次实际扩张

| 区块 | 原始矿地与推进条件 | 建造后布局 | 成长规则 |
|---|---|---|---|
| 0 出生营地 | 唯一初始可走区 | 小主堡、营房、仓棚 | 10 金币建城 Lv1 |
| 1 居民与锻造街 | 第一块低级矿地；基础镐可挖；可提前捐献，付满爆破 | 前沿围挡拆除，主街延长，锻造铺和住宅落地，城门前移 | 原城 Lv2 升级费 15 金币；解锁武器 Lv2 |
| 2 工坊与龙巢 | 第二块低级矿地；基础镐仍可挖，武器 Lv2 可处理守卫 | 工坊、龙巢与两侧支路形成完整街区；旧营地仍可返回 | 原城 Lv3 升级费 20 金币；锄头台与免费孵化巢解锁 |
| 3 前哨城关 | 中级矿地；先在区块 2 获得锄头 Lv2 | 前哨建筑、新城门；现有升级入口迁到前沿，进度保留 | 原城 Lv4 升级费 100 金币；武器 Lv3 解锁条件保持城 Lv4 |

没有额外“买地费”。扩区付款直接替代原城升级，不在原升级之上再收一次钱。

高级矿和封印场地作为区块 3 外的战斗目标，不继续改造成居民区。进化仍须满足武器、宠物与高级矿进度条件，不能因为庭院提前有了物理位置就提前付费进化。最后一波仍在通往封印的前线战斗区域发生。

### 捐献与爆破规则（2026-09-11 最新要求）

状态顺序：`矿地 → 筹款与采矿并行 → 付满立即爆破 → 施工 → 已建成`。不再要求先清空矿体或打死该区守卫才能捐献。

- 保留原成长顺序：完成上一街区解锁的必要工坊升级后，即可为下一块捐款；金额仍为 15 / 20 / 100 金币。
- 地贴与“就地捐献”按钮共享唯一进度。按钮只捐本次点击时选择的现有金币，最多到剩余费用；不自动挪用之后捡到的钱，不因移动停止这笔已确认的捐献。
- 未付满保留已捐金额；付满当帧炸开固定建设用地中剩余矿柱，接着生成街区。外围可选矿、未来街区、高级矿和封印不被这次爆破波及。
- 矿体渲染和阻挡计数同时清除。矿中金币、按矿格计算的金币及宝石按原产量释放、自动回收；守卫正常出土，继续战斗和掉钻石，不凭空增发资源。
- 碎矿实际向外飞出，地面和建筑按原施工流程出现；爆破和购买回调幂等，不能重复收钱或重复发矿产。
- 不再安排返回旧矿区的炸药桶。旧矿边角仍可自主采集，但主线箭头只引导当前及更前方目标。
- C 的常用工坊入口设置在新区前沿；同一升级只保留一个入口，迁往前沿时保留已交材料，旧地贴撤除。龙蛋在龙巢来路上，晚孵化时龙蛋和巢一起移到前哨。高级矿打通后，进化地贴在当前缺口附近的安全地面出现。
- 四级锄头保留为可选强化，不强制回头购买，不阻拦进化与终局。

## 4. 建成动画必须表现结构变化

一次扩建约 1.5–2 秒完成，不做长镜头锁定：

1. 旧前沿围挡或临时城门收起；它们对应的碰撞同步移除。
2. 铺路与施工从旧街口向新地块远端推进。
3. 两侧建筑依次升起，新设施、入口和支路同时可用。
4. 新城门在区块远端落地，下一处开拓目标出现在门外。

地面颜色只作为辅助。必须能看到新街区的轮廓、建筑体量、入口和城镇前沿位置发生变化。建筑应放在可走主街两侧的实际用地内，不再用岩壁顶上的小屋代替城区。

禁止在玩家或宠物脚下生成碰撞。施工前规划净空，保留贯穿新旧城区的主街；若实体占着建筑地基，延迟那栋建筑落地，不强制传送玩家。

## 5. 设施位置与返回成本

- 主堡固定在区块 0；升级主城改由前沿地贴执行，不用每次跑回主堡。
- 锻造铺随区块 1 建成出现；锄头工坊和免费龙巢在区块 2 出现。
- 龙蛋仍要玩家捡起、抱回区块 2 的龙巢放下。蛋的位置要保证在现有工具可达路线中，不能被“必须先孵化才能升级”的路径锁住。
- 区块 3 建成后提供工坊的前沿服务入口，与旧工坊共享等级、费用、已付款进度；旧设施保持可用，不复制奖励或二次收费。
- 免费孵化、钻石支出规则、出生金币、敌人掉落等共同改动继续继承。路线和节奏会改变，需重新测量，不能再要求 C 与 A 的 marks 完全相同。

## 6. 实现范围与旧约束替换

C 是独立布局实验，A/B 保持现状。保留一份母版生成三个页面，但为 C 使用单独的地图布局数据、区块状态及设施锚点；不要仅在 `clearOreNode()` 上加贴花。

建议实现拆为：

- `C_DISTRICTS`：区块边界、前后邻接、建设矿集合、建筑位置、主街净空、设施锚点、前沿门。
- 区块状态机：矿体/守卫完成度、成长前置、付款、施工、设施启用、下一块开放。
- C 专用引导与碰撞：按已开放区块寻路，禁入未开放建设区；旧门拆除、新建筑落位与碰撞同帧更新。
- C 专用镜头取景：出生读到窄营地，扩建后能读到新旧街区相接，持续跟随当前活动前沿。

**废止旧 C 的三项限制**：“所有半径不许改”“可行走范围不能变化”“A/C 总时长与 marks 必须完全一致”。这些限制正是旧方案只能做表面装饰的原因。C 可重排地图、建筑、入口和边界；改动不得泄漏到 A/B。

不直接改 A/B 共用的半径来实现 C。旧 `citygrow` 铺地实现应替换或删除，不能与新布局叠加。旧页面、截图及测试只能作历史资料。

## 2026-09-11 地贴付款流程修正

用户复现：背包有 27 金币，站在首个 0/15 扩建地贴却没有付款。检查发现此前 `blockReady` 要求整段矿 `cleared`，把建设区外的边角矿也计入前置；阻断文案仍错误要求先升级锄头。原自动路线会先挖完整段矿，未覆盖这个停留场景。

本次修正：

- 使用矿柱实际占地与下一街区矩形建设边界相交来计算清理条件；外围可选矿不阻断扩建。建设区有虚线边界，地贴显示清理柱数、守卫状态或可付款状态；箭头优先指向建设用地中的剩余矿柱。
- 工具所需宝石落在建设用地内；若延迟开放资源时该用地已经清空，按原产量掉落，不把必需宝石埋回外围可选矿。
- 站在地贴上持续显示实际阻断原因；补钱、前置条件变化后直接继续付款。部分支付保留，缺金币、缺特定品质资源和前置未完成分别提示。
- C 四级城建成时立即开放工坊，不再等 1.5 秒 watchdog；前后工坊入口切换保留同一付款状态，不误加重新进入锁。
- 旧采矿工坊完成升级后保持入口位置及重新进入保护，避免移动到前沿又切回旧入口时连续扣掉下一档费用。
- 重新进入保护保留，但明确提示离开地贴后再进入；不会静默忽略玩家。
