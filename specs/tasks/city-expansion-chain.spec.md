# Task: 主城升级扩张与功能解锁链

## 目标

把「挖矿 → 前线建房 → 换武器」的线性推进改为「回城升级主城 → 主城扩张 → 解锁新功能地贴」的循环，并让开局第一件事就是把主城建出来。

## 开局规格

- 玩家出生在城北广场 (0,-1.5)，背上已有一批启动金币。
- 出生朝向直接对准「建设主城」地贴，玩家不需要先转身找目标。地贴在正北，所以这一朝同时也朝着矿区。
- 广场里显示「建设主城」建造格，费用与启动金币相等。
- 教程提示改为「走进光圈，建设你的主城」，手势指向中心。
- 地面从玩家脚下向地贴淌出一串箭头，开始游戏前就已经亮着。
- 玩家走进建造格后自动逐枚付款，主城第一版升起。
- 建成瞬间：
  - 主城旁出现「升级主城」地贴。
  - 玩家金币归零，升级地贴显示为不可支付状态。
  - 朝屏幕上方那道低级矿墙亮起，箭头指向矿墙（人在围墙背后时先指出城口）。
- 首次输入后若玩家长时间不动，重新播放指向中心的手势提示。

## 主城形态

主城共 4 个形态，占地逐级向外扩张：

| 形态 | 半径 | 触发 | 视觉变化 | 解锁 |
|------|------|------|----------|------|
| L1 | 6.6 | 建设主城 | 地板、围墙、主堡底座、2 栋民房 | 升级主城地贴 |
| L2 | 9.8 | 第一次升级 | 占地扩大、主堡长出塔身、+4 栋民房 | 升级锄头地贴 |
| L3 | 12.2 | 第二次升级 | 继续扩大、主堡加冠锥顶、+7 栋民房 | 孵化台地贴 |
| L4 | 14.6 | 第三次升级 | 最终形态、主堡挂旗、+12 栋民房 | 宠物进化地贴 |

- 每次扩张沿用现有地板铺开、网格闪光、构件升起和完成高光演出。
- 旧形态的地板、围墙和设施全部保留，不下沉、不删除。
- **主堡分段随等级长高**，从 2.4 米的底座长到 6.95 米的完整塔楼。占地和碰撞半径四级不变，长的只有高度。原先 L1 就把完整塔一次立完，之后三次升级玩家看到的变化只剩地板往外扩一圈——那是最弱的成长表达。
- 扩张只向外推进，不得覆盖最内层矿墙的位置。建筑群外缘到自由圆之间那条环城道（Lv4 外缘 14.6，自由圆 16.3）保留，但它已不再是动线的一部分：地贴北移之后玩家出城走的是正北那条直线。
- 扩张后重建碰撞时沿用现有动态脱困，避免把玩家封在墙内。城南房子的碰撞圈成片重叠，脱困必须多轮推挤并兜一次合成方向，单轮会收敛出哪边都走不动的死点。

## 城内布局与清空区

城内密度和玩家动线是一对矛盾：房子摆得密才不空旷，但摆密了就把路堵了。解法是把两者在空间上分开——玩家只在城北活动，城南整片让给建筑。

**广场（城北）**：出生点、四张功能地贴、出城口全部集中在这里。玩家全程只在「广场 ↔ 扇形矿区」之间往返，来回都是直线。

**清空区**是一块 T 形区域，其中不允许存在任何带碰撞的物体：

| 区段 | 范围 | 作用 |
|------|------|------|
| 地贴区 | \|x\| ≤ 7.5，z ∈ [-11.5, -2.0] | 四张地贴摊开的活动区 |
| 中轴 | \|x\| ≤ 3.0，z ≤ 0 | 出生点到出城口的直线 |

- 中轴南界停在 z=0，不往城南延伸。延伸到 z=2 的话，主堡（碰撞半径 2.4，位于 (0,4.5)）会伸进来 0.7 米；而把主堡再往南推，L1 那个半径 6.6 的小城就装不下它。
- 校验由 `cityClearViolations()` 承担，调试接口 `__wik.clear()` 返回空数组才算布局合法。城内坐标全是手填的，挪一栋房子很容易压到路上一点点，而这种问题在自动演示里只表现成「人卡在城里不动」，从现场看不出是哪一栋伸过来的。
- **注意校验只覆盖碰撞体**。城墙角楼这类纯视觉物件不进碰撞表，查不出来，得单独确认它不落在动线上（角楼原先的 225°/315° 两座就正好压在锄头和孵化台地贴旁边一米半处）。

**城南**是纯观赏区，玩家进不去也不需要进去：主堡的碰撞圈和两侧民房把中轴堵死（净缝 1.2 米 < 玩家直径 1.24），各级都封闭。因此那边的碰撞圈可以随意重叠、密度拉满。

**广场的填充只能靠不带碰撞的东西**。而且竖屏下水平视野只有玩家左右九米上下，清空区又要求房子退到 \|x\| ≥ 9.5 之外——两侧那排民房在竖屏里其实进不了画面。真正撑住画面中心的是旗杆：四米六高，地面只占一个点，是俯视下画面里唯一有高度的东西（火炬只有两米，太矮）。旗杆位置需要避开地贴方块和行走路线两米以上，否则俯视投影会把旗面压到玩家头上。

## 功能地贴

主城内的地贴统一使用现有方形贴地建造格，走进即自动付款——但**只有轮到的地贴才收钱**。

「走进即付款」意味着玩家穿过主城时金币会漏进沿途的格子。如果不加限制，还轮不到的地贴会被提前喂饱，推进顺序就变成由走位决定（实测会出现「带着二级锄头站在高级矿墙前」的死局）。因此每个地贴都有付款前置条件，轮不到时站上去不扣钱并给出提示。

### 升级主城

- 常驻，直到主城达到 L4。
- 每次升级费用递增。
- **付款条件：`锄头等级 ≥ 主城等级`**。锄头没跟上时不收钱，提示「先升级锄头凿开下一层矿，再扩建主城」。
- 完成后播放扩张演出并解锁对应新地贴。

### 升级锄头（L2 解锁）

- 可重复升级，提升挖矿效率。
- 每级提升单次命中移除的体素数量。
- **付款条件：`主城等级 ≥ 锄头等级 + 1`**。主城没先扩建时不收钱，提示「先扩建主城，才能解锁下一级锄头」。
- 升级后英雄手中矿镐外观变化，挖矿特效增强。
- 每一级对应一道矿墙：Lv1 低级、Lv2 中级、Lv3 高级。等级不足时对应矿墙完全凿不动。

两条互锁条件展开后锁死一条固定链：`建城 → 城2 → 锄2 → 城3 → 锄3 → 城4`，孵化台在城 3 之后按拿到蛋的时机插入。好处是配平数值时不会打乱流程顺序。

### 孵化台（L3 解锁）

- 玩家未持有龙蛋时显示为空巢，不可支付。
- 玩家抱蛋靠近时允许支付，付款后龙蛋放入巢中并孵出宠物。
- 孵化完成后地贴转为宠物进化的前置。

### 宠物进化（L4 解锁）

- 需要已孵化宠物才允许支付。
- 支付完成后播放进化演出，宠物形态与输出提升。
- 进化完成是最终 Boss 的触发条件之一。

## 引导优先级

引导箭头按以下顺序解析目标，候选地贴必须**同时**满足「轮得到」（付款前置条件成立）和「付得起」（金币 ≥ 剩余价格）：

1. 主城尚未建成 → 中心建造格。
2. 地上有龙蛋 → 龙蛋。
3. 持有龙蛋 → 孵化台。
4. 有宠物且未进化 → 进化台。
5. 升级锄头。
6. 升级主城。
7. 其他情况 → 锄头凿得动的最外层矿墙。
8. 已经没有挖得动的矿 → 回指轮得到的地贴（钱不够也让玩家先站上去，边挖边补）。

不满足条件的地贴不参与竞争，否则玩家会被箭头指着一个收不了钱的格子干站着。

## 地面引导箭头

屏幕箭头贴在角色附近，视线扫过去容易漏掉，因此地面上再铺一层指路箭头。两者共用同一个目标解析。

- 箭头贴地，沿玩家到目标的方向排成一列，顺着方向循环前淌，两端淡入淡出。
- 数量随距离伸缩：六米左右的近距离只放两个，远距离最多三个，避免挤成一坨。
- 起点离开玩家两米以上，否则俯视视角下会被角色自己挡住。
- 末端在接近目标时淡出，不遮挡地贴上的价格读数。
- 目标距离小于 2.8 米时整组隐藏；结算 CTA 与结局演出期间同样隐藏。
- 与屏幕箭头不同，地面箭头在玩家首次输入之前就显示——它的职责就是让玩家迈出第一步。
