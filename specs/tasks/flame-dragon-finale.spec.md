# Task: 火焰巨龙出场演出与下载结算

## 目标

当玩家已经打通高级矿并让宠物完成进化时，触发最终 Boss 火焰巨龙。巨龙封印在**高级矿再往外一层的「封印矿」**里，镜头切向那段矿墙，看它烧红、崩裂，巨龙破土而出，收在「我方已蓄势待发、下一秒就要开打」的对峙画面上，在玩家跃跃欲试的情绪峰值弹出下载 CTA。

巨龙不从天而降——它一直被封在玩家一路挖过来的这条矿脉最深处。玩家不需要亲手把它挖出来，破封由演出直接完成。

**封印矿是玩家凿不开的第四层**（见「封印矿层」）。这一层的存在是为了让「凿不开」这件事本身成为叙事：
玩家挖穿高级矿之后会撞上一道更硬的墙，凿它只有弹开和一句「里面封着的东西还在动」。
把巨龙放在玩家能挖开的那一层里，逻辑上就该由玩家亲手挖出来——而 playable 的时长不允许再加一层开采，
真挖开了也会变成「玩家把 Boss 挖出来打」，破封演出的主角就从巨龙变成了锄头。

**本局不演出击败巨龙。** 战斗本身是留给正式游戏的钩子，playable 只负责把期待感拉满然后收口。

## 触发条件

同时满足：

1. 宠物已完成进化。
2. 玩家已经开采过高级矿（至少清空一个高级矿体）。

条件满足后延迟极短时间进入演出，避免和当前战斗或付款演出叠加。

## 封印矿层

高级矿之外再加一层 `sealed`，是玩家在正常流程里**永远凿不开**的墙。

| 项 | 值 | 理由 |
|----|----|------|
| `ringRadius` / `ringThickness` | 45.2 / 3.6 | 落在高级矿外缘（40.2）和场地边缘之间 |
| `ringHeight` | 6.2 | 比高级矿（5.4）高一截，挖穿高级矿之后抬头就看得见 |
| `requiredPickaxe` | 4 | 锄头最高只有 3 级，条件永不成立 |
| `cellsPerCoin` | 0 | 不产币 |
| `sealed` | `true` | 生成层和规则层都靠这个标志分流 |
| `segmentCount` | 4 | 决定烧红演出的分辨率，见「矿墙烧红」 |
| 配色 | `color 0x050b12` / `emissive 0x0e3a5a` / `chunk 0x4a93bd` / `glow 0x62c8ff` | 深青，见下 |

为了给它腾地方，高级矿从 39/6 内移到 **37.5/5.4**。让位的量是被终局构图定死的：
对峙时玩家站在破封点内侧四米、侧向七米处，那个落点的半径是 41.8，必须落在高级矿外缘和
封印矿内缘（43.4）之间那条空走廊的正中，否则他会被塞进实心矿墙、下一帧被碰撞推出画框。
径向格数不动，所以挖穿一条隧道要凿的格子数没变，只是每格薄了一点。

**这一层不埋金币、不冻守卫。** 凿不开的墙里还闪着金币，等于挂一份领不到的赏金，
玩家会一直砸下去而每一下的回应都只是弹开；守卫立在里面也永远等不到出场的那一刻——
它封的是巨龙，那道剪影由终局演出自己放进去。

**规则层的三处分流：**

- `pickaxeTier()` 跳过 `sealed`：锄头图标的颜色不能取这一层，否则 3 级锄头会显示成
  「能挖封印矿」的样子。
- `rejectMine()` 换文案：`「封印矿凿不开，里面封着的东西还在动」`，不是通用的
  「回主城升级锄头」——那句话在这里是假承诺，城里没有能解开它的升级。
- `getNearestOre()` 默认排除 `sealed`：它是引导箭头和恐龙蛋落点的取样源，
  指向一层凿不开的墙等于把玩家推进死路。

**揭示时机**：挖穿高级矿的那一刻（`onTierProgress` 里 `breachedByTier.high === 1`）
提示`「走廊尽头是封印矿，凿不开，里面封着东西」`。这句话只做预告，不给收益承诺。

**配色是试出来的，不是挑出来的。** 矿石最终的颜色由自发光的色相说了算——albedo 会被
场景光和 sRGB 编码一起提亮到中间调，压不住。所以第一版的黑底金光渲染出来是一片土黄，
像沙坡；换成熔岩红又和身后那道高级矿糊成一片（走廊里两道墙是前后叠着看的，都取暖色
就分不出人站在哪道墙前面）。冷色是唯一还空着的位置——前三层占了绿、紫、橙。
顺带它也是衬火最好的背景：巨龙在里面越烧越亮的那一段，红光压在青底上最跳，
崩出来的冰蓝碎块混在火里也一眼分得清哪些是墙、哪些是火。
不透明度给到 0.94（其余层 0.46）：这层要读成「实心到透不过去」。

## 破封点

`sealedDragonSite()` 在**封印矿墙**的中心线上取点。
沿弧转开一段，保证和玩家之间至少留出二十二米——在脚边破土的话镜头框不下双方。
玩家站在场地正中时弧上任意一点都够远，直接取他正对的方向。

矿区收成扇形后这个点必须**夹在扇区内**（留 0.06 弧度余量）：转出扇区就落到侧面岩壁背后，
玩家走不过去，镜头里也只剩一堵石头。而夹进来之后取到的点常常贴着扇区边缘，
对峙站位又要另外处理（见「对峙站位」）。

**取到点之后还要把角度吸到最近那段封印矿的正中。** 烧红是按整段换材质做的，段与段之间
有一条硬边界；而破封点按「离玩家最远」挑出来，落在段内哪儿全凭玩家位置。压在接缝上时
巨龙剪影会一半躺在烧红的墙里、一半躺在还青着的墙里，读起来像它卡在两堵墙中间，
而不是要从这一段里挣出来。只吸角度、不动半径，径向的位置关系全都不变。

## 出场演出

演出期间接管镜头与输入。巨龙不是从天上俯冲下来的，而是一直封在封印矿脉里：
沉在 y = -1.6 处、以剪影的形式透过矿墙显形，蓄力躁动一秒七后顶碎矿墙钻出来。
这样最终 Boss 和玩家一路挖过来的这条矿脉是同一件东西，动机比「天上飞来一条龙」自洽。

| 时间点 | 内容 | 取景 |
|--------|------|------|
| 0 | 切镜到破封点，矿墙烧红、震动、崩渣，剪影往外顶 | 切到 `framingDistance(23, 34)` 后推近到 `(20, 28)`，视点 4.5 |
| 1.7 | 顶碎矿墙钻出 | `framingDistance(11, 25)`，视点 5，中心沿朝向挪 4 |
| 2.9 | 展翼咆哮，打出标题 | `framingDistance(15.5, 26)`，视点 6.2，中心沿朝向挪 横屏 2 / 竖屏 10 |
| 4.0 | 喷火 | 沿用上一镜 |
| 5.3 | 对峙定妆，出 Boss 血条 | `framingDistance(16, 28)`，视点横屏 4 / 竖屏 5，中心沿朝向挪 横屏 0 / 竖屏 5 |
| 8.6 | 收黑边，弹 CTA | — |

1. 冻结玩家输入并清零移动。
2. 演出全程使用程序化几何与粒子，不引入外部资源。
3. 演出期间不结算任何伤害，Boss 血条始终满格。
4. 对峙镜同框显示巨龙、玩家与已进化宠物，宠物做备战姿态。

### 第一拍必须是切镜

相机平滑跟随要一秒才从玩家头顶飞到最外层矿脉，而蓄力总共只有 1.7 秒——等它飞到位，
矿墙都该炸了。所以 t=0 先 snap 到一个略远的机位，再把目标设成推近后的机位，
1.7 秒里一路缓慢推近。蓄力和破封共用一个机位方向，只推近不切镜：
切一刀会打断「就是这段墙要裂开」的注视。

### 机位方向

只能摆在矿墙内侧的高处：沿切线看视线会全程贴着矿墙走，从外侧看则被矿墙自己的弧度挡死。
侧偏要收窄：偏得多了矿墙两侧就不对称，靠相机那侧的残墙占掉半个画面，
另一侧的直接被推出画外，缺口读起来像矿脉的尽头而不是一个洞。

**高度这一项是硬要求，而且随着破封点搬到封印矿又抬了一档。** 挡在视线里的不再是
又矮又远的中层矿墙，而是紧贴在封印矿身后三米的**高级矿墙**——它高 5.4、离破封点只有
五到十米，比原先那道墙难越得多：蓄力和破封两拍从 0.6 抬到 **0.82**，咆哮拍从 0.42 抬到
**0.62**。不抬的话前景下半截全是那道橙色半透明墙，巨龙的腿和缺口地面全糊在后面。

**基准方向取「从场心指向破封点」的径向，不是「从玩家指向破封点」。** 玩家在城里时两者
差不多，但终局可以在凿穿高级矿的那一刻触发，那时他已经站在走廊深处、和破封点几乎在
同一条弧上——两点连线于是变成切向，整套构图跟着绕到矿墙侧面去（实测咆哮那一拍包围盒
右边界到了 NDC 3.4），前景塞满墙体。这套镜头本来就是按「越过前两道墙顶俯视缺口」设计的，
只有径向成立。玩家站哪不影响构图——对峙前 `braceForBattle()` 会把他挪到 standPoint。

### 两种画幅的取景

`framingDistance(width, height)` 取「装下这个宽」和「装下这个高」两个距离的较大值。
竖屏的横向视野只有二十来度，一直卡在宽度那一项上；横屏因为纵向被压扁，卡在高度那一项上。
所以调高度只影响横屏、调宽度只影响竖屏，两个画幅可以分开配平。

**宽度这一项要按「竖屏愿意框多少」给，不是按物体实际尺寸给。** 巨龙连翼展带尾巴二十二米，
照这个数给宽度，竖屏会把机位推到七十米外四十米高，整个场地连三道矿墙一起收进画面，
主体缩成一小块——而且相机会穿过场地中心跑到对面，视线横穿内层两道矿墙，抬多高都挡得死。

竖屏装不下巨龙的翼展，只能靠**挪构图中心**来选择保住什么：

- 破封镜沿朝向挪 4：顶出地面这一下最需要看见的是脸，中心压在破封点上会把龙头甩到画外。
- 咆哮镜竖屏挪 10、画宽给 15.5：这一段要框的是「龙身前部到火舌尖」这十五米——龙嘴在
  破封点前七米，火舌再往前十二米。挪 8 配画宽 14 时火舌最后四米出框（整条火舌的三分之一），
  改成挪 10 / 宽 15.5 之后出框的只剩一米，那一截冲出画外反而是喷火该有的势头。
  横屏画宽四十四米，双翼连火舌一起框得下，挪多了反而把翅膀切掉，所以只挪 2。
- 对峙镜竖屏挪 5：龙头和玩家都在这一侧，不挪的话龙头贴着画框、玩家挤在边缘那一小条上，
  读不出两边在对视。横屏不用挪，翼展框得进来。

注意锚点和视觉中心不是一回事：蓄力镜的剪影锚点沿弧退了四米，但它的头颈正好朝反方向
伸出八米，可见那片的视觉中心又落回了破封点——这一镜的中心不需要挪。

### 玩家的对峙站位

`braceForBattle()` 把玩家和宠物挪到**破封炸开的那个缺口里、巨龙的侧前方**，跟巨龙同在最外层。
这一挪发生在镜头正对巨龙特写、玩家不在画面里的那一拍，观众看不到位移。

他触发演出时多半还在城里，隔着四道墙，不挪的话对峙镜要框进四十米纵深，双方都缩成小点。
早先让他站在中层与高层之间那条走廊上也不行：从内侧看过去人整个埋在中层矿墙后面，
要抬到能翻过墙顶，镜头得退到六十多米，而场地半径只有四十八米——相机会跑到对面去，
视线横穿三道墙。挪进缺口之后视线能从墙顶上方擦过去两米多，双方都露在缺口的空地上。

**落点半径 41.8 是走廊的正中，不是随手取的。** 破封点内侧四米、侧向七米合成出来的半径
恰好落在高级矿外缘（40.2）和封印矿内缘（43.4）之间那条五米宽走廊的中线上，两边各留
1.6 米，减掉玩家半径 0.6 之后还剩一米的间隙。这个数字是高级矿内移量的反向约束：
先定死站位要在走廊正中，才反推出高级矿必须让到 37.5/5.4。

对峙镜里前景仍会盖着一片半透明的高级矿墙——那是相机高悬俯视时墙顶朝向镜头的必然结果，
不是站位问题。矿石半透明，玩家和宠物透得出来；这一拍的主体是巨龙和血条，可以接受。

**站位要跟着扇区镜像。** 破封点是按「离玩家最远」挑的，挑出来常常贴着扇区边缘；
站位又是从破封点沿切向外偏七米，一偏就偏到侧面岩壁背后，被裁回来之后人站在画框外，
对峙镜里只有龙。所以先拿两个方向各试一次，取偏完之后离扇区中心线更近的那一边——
站位、巨龙朝向、相机侧偏都从同一个切向量算出来，取反等于把整组构图整体镜像到扇区内侧。

### 镜头穿过矿墙

对峙镜要贴着地面从城里拍向巨龙，中途会穿过半透明矿墙。矿石糊在镜头上就是一层洗白整幅
画面的雾。`updateOreLensClip()` 每帧检查镜头钻进了哪一段矿墙（水平距离 < 3 且低于矿墙
顶面），把那一段临时藏起来；演出结束自动恢复。只在演出和 CTA 期间生效——游戏中镜头恒定
悬在焦点上方 26，不可能碰到矿墙。

### 封印显形

四层半透明矿石叠下来透光率不到一成，把巨龙摆进矿墙里是全黑的。沿用守卫剪影那套：
关掉深度测试、把绘制顺序抬到矿体之上，深色轮廓压在高饱和的矿石上，
读出来就是「这段矿墙里嵌着一条龙」。配套的几条：

- 翅膀、四肢和尾巴要收掉。它们伸出去的部分会落在矿墙轮廓外，而剪影不受地面遮挡，
  垂到地下的那截会直接糊在内侧空地上。
- 只沉一米六。可见那片身体从下缘到头顶跨五米半，正好是封印矿墙的高度（6.2）；
  再沉下去剪影底部就垂到地平线以下，糊在画面下方那道橙色高级矿墙上。
- 锚点沿弧退四米。侧身之后头颈还要沿着弧往前伸八米，压在破封点上的话整片剪影会
  偏出去半个画面，跟烧红的那段墙也对不上。
- 眼睛要放大到两倍并染成红色。隔着矿墙看，一双眼睛是「石头里有东西」最快被读懂的信号。

### 矿墙烧红

破封点埋在三米多厚的矿墙里，贴地光斑和穿墙光柱都会被墙挡掉或者变成一根戳在矿脉上的
实心烟囱，躁动只能做在矿墙材质上：把破封点所在那一段矿体的材质单独克隆一份
（tier 材质是整层共用的，直接改会让整道墙一起亮），`emissive` 烧到强橙红并随蓄力进度加强。

- **烧红的范围按「段」取，不按固定半径取。** 封印矿的段中心相隔十七米半，而破封点是
  贴着扇形边缘挑的；原先那个十米的半径阈值会一段都够不着，整个「墙在烧」的铺垫直接消失。
  改成排序取最近的那一段，外加确实挨着它的邻段（阈值 10 米，正常只会选中一段）。
- **封印矿切四段，不是两段。** 段数在这一层不表示「几只守卫」（它没有守卫），而是烧红
  演出的分辨率：切两段时一段就有三十五米宽，比破封镜头的画宽还大，整个画面会烧成一片，
  看不到两侧还青着的墙作对照——「这一段要裂了」就退化成「这里本来就是红的」。
  切到四段每段十七米半，刚好占画面中间一截。总格数不变，代价只是多两个 draw call。
- **高级矿要压暗，自发光和底色一起压**（`emissiveIntensity` 0.1、`color` 乘 0.35）。
  它紧贴在封印矿身后三米，在破封镜头里是整个前景，而它那身暖橙比封印矿的深青亮得多——
  只压自发光的话，画面读起来会是「巨龙躺在一片橙色矿脉上」，而不是「巨龙封在青色的墙里」。
  底色压到三成五之后前景退成暗褐，封印墙才浮得出来。压之前要留一份原色：
  `multiplyScalar` 是就地改的，不存原值破封后就调不回去，高级矿会一直暗着到片尾。
- **封印矿自己不能跟着压。** 它本来就是近黑的底色，再压一档整道墙会黑成背景，
  冻在里面的巨龙剪影就成了浮在空地上的一团影子——「封在矿里」这件事本身没了。
  它的对比靠的是另一头：破封段单独烧红，同层其余段保持原样。
- 缺口只开到刚够巨龙站进去（粉碎半径十米），两侧要留下可见的残墙，
  否则读不出它是从矿脉里挣出来的。
- **崩塌和碎块只作用于封印矿**：`eruptOreChunks()` / `pulverizeOreAround()` 都要带上
  `tierId = 'sealed'`。不过滤的话半径十米内的高级矿会一起被炸掉，玩家挖穿的那条隧道
  凭空变宽，而且飞出来的橙色碎块和封印矿的冰蓝混在一起，看不出崩的是哪道墙。

### 火焰

单层加色锥在夜色背景上只会亮成一片灰褐，看着像烟不像火。改成两层同轴锥体：外焰
`(2.05, 8.5, 0xff2a00, 0.44)` 罩住整条火舌，内焰 `(1.05, 5.6, 0xff8c1a, 0.3)` 是短一截的
亮芯。两层都是加色混合 + 双面 + 关闭深度写入 + 关掉雾（几十米外雾会把加色的火舌冲淡成灰烟），
锥尖在龙嘴、锥底朝外，形成向外张开的火舌。

**两层锥各有前后壁，重叠处一共四层加色，要控的是绿蓝两个通道而不是总不透明度。**
红通道叠到饱和正是火该有的亮度；但只要底色带上高绿高蓝（比如浅橙 `0xffcc7a`，G=0.8 B=0.48），
四层叠完三个通道一起顶到 1.0，整条火舌就在夜色里读成一片灰白的布。
靠压低不透明度去躲这个问题会把火压成半透明的灰三角，得从颜色下手。
