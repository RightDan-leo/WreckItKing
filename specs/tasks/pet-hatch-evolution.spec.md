# Task: 龙蛋孵化与宠物进化

## 目标

玩家在野外矿区击杀中级以上野怪时获得龙蛋，抱回主城孵化台孵出宠物；宠物跟随玩家自动参战；主城达到最终形态后可以让宠物进化，进化完成是最终 Boss 的触发条件之一。

## 龙蛋

- 由中级及以上矿的野怪掉落，落地后原地发光旋转。
- 玩家靠近并站稳，锁环转满后拾起。
- 抱蛋期间：双手被占，收起矿镐，不能挖矿也不能攻击。
- 抱蛋期间金币仍可正常拾取与堆叠。
- 抱蛋时引导箭头指向孵化台。
- 若孵化台尚未解锁，提示需要先升级主城。

### 出现时机

蛋不能早于孵化台解锁（主城 Lv3）：抱蛋就挖不了矿，早给等于把玩家的收入掐断一段。
所以「击杀守卫掉蛋」这条路径带着 `cityLevel >= 3` 的门槛。

但**这条路径几乎必然错过**，不能当作蛋的主要来源：贯通中级第一段只要二级锄头，
四十五秒上下就发生了，而门槛要等到五十七秒——守卫早死了十秒。于是蛋只能等第二段的守卫，
可第二段常常压根不用挖（第一段那条隧道就够赚出下一步的钱），孵化因此在
「锄头三级之前」和「之后」两边来回跳，中级段该有的孵蛋和宠物整个滑出那一段。

因此实际时机由 `ensureEggAvailability()` 决定：**主城到 Lv3 且玩家已经凿穿过一段中级以上的矿墙**，
蛋就直接给，不等任何守卫死。落点取离玩家最近的那段矿。

- 这个兜底在整环时期几乎不触发（中级矿八段八名守卫，总有一个死得够晚），
  扇形化把中级砍到两段之后它变成了常规路径。
- 判断不能写成「还有守卫活着就等」：守卫被引开、被绕过、拖到下一段才回头打，
  死亡时机能差三十秒。
- 落点不能取中级矿段的中心：那个点在墙体里，找空地时会被推到墙的外侧去，
  玩家得先钻过隧道才能捡，白等十八秒。

### 蛋头上的名牌

> 注：本节以上的「由野怪掉落」「落点取离玩家最近的那段矿」已经过时——蛋现在固定摆在
> 中级矿与高级矿之间那条走廊的中线上（半径 32.45，扇形中线），开局就在那儿。
> 理由见 `eggSitePosition()` 上方的注释。下面这条正是建立在固定点之上的。

固定点的设计意图是「早早看见、很久之后才拿到」：玩家凿穿低级矿、第一次站进走廊时就能看到远处有东西等着，而走到 32.45 得先凿穿中级矿。承担这个信号的是那枚屏幕空间的锁环（出画自动隐藏）。

但锁环只说「那边有个东西」，没说是什么、也没说能拿它干什么——它本身是个进度环，读不出对象。所以在环上方挂一块名牌：`龙蛋` / `走近搬回主城`。

做成 `#egg-lock` 的**子元素**而不是另开一个 fixed 层，是为了白拿锁环已经验过的两件事：屏幕投影定位（`updateEggLockPosition()`），以及出画与拾取时的隐藏——父元素的内联 `opacity` 会一起盖住子元素，不需要再写一份同步逻辑。实测拾取那一帧名牌随环一起消失，没有残留。

配色用紫（`#d8b4ff`）而不是环的黄：环的黄管的是拾取进度，名牌管的是「这是什么」，两件事分开；紫色同时和蛋壳、和拾取爆点的 `0xc08bff` 对上。

文案不随孵化台是否解锁而变。「搬回主城」两种情况下都成立（孵化台就在城里），而拾取时机的那句区分已经由 `pickUpEgg()` 的 toast 承担（`cityLevel >= 3` 分两路）。一块会在玩家走近过程中改字的名牌只是噪音。

## 孵化

- 孵化台由主城第二次升级解锁。
- 玩家抱蛋走进孵化地贴后开始付款。
- 付款完成后：龙蛋从手上飞入巢中，播放孵化演出，宠物破壳。
- 孵化完成后双手解放，矿镐恢复。

## 宠物

- 宠物以固定偏移跟随玩家，带轻微漂浮和滞后。
- 自动锁定玩家附近的敌人并发射远程弹道。
- 宠物不会被击杀，不参与碰撞。
- 宠物在玩家挖矿时不攻击矿体。

### 数值（`BALANCE.pet`，2026-09-08 重排）

| 形态 | 单发伤害 | 射击间隔 | 射程 | DPS |
|---|---|---|---|---|
| 破壳 | 520 | 0.45s | 10 | 1156 |
| 进化 | 1150 | 0.30s | 14 | 3833 |

原先是 180 / 0.85s（212 DPS）和 620 / 0.42s（1476 DPS）。破壳那一档在数值上几乎不存在——
它只占玩家当时输出的 11%，实测高级守卫带不带它是 4.6 秒对 3.9 秒，「多了个帮手」这件事
玩家只能从画面上看出来、从手感上看不出来。

**加倍时优先压间隔而不是加单发。** 中途试过 460 / 0.62s（同量级 DPS），高级守卫那场只快
15%，中级那场一点没快：火球有飞行时间，一场两三秒的仗里小龙只来得及打两三发，单发再大
也有一发落在怪已经死了之后。包更小更密才吃得满，顺带也更像「有个东西在替你打」。

推导与实测见 [power-spike-tuning](power-spike-tuning.spec.md)。那份文档里还有一条不属于
数值、但决定这一档能不能被感觉到的改动：武器 Lv3 的钻石价从 6 抬到 12，好让「破壳」和
「弓 Lv3」之间隔着一场真正的仗——原先两者只差 2.7 秒且中间没有任何战斗，体感上糊成一次。

## 进化

- 进化地贴由主城第三次升级解锁，且必须已孵化宠物。
- 走进地贴付款后播放进化演出：
  - 宠物升空并被光柱包裹。
  - 体型放大、颜色变化、增加翼展与特效。
  - 落地后输出与攻击频率明显提升。
- 进化完成后设置 `petEvolved` 标记，用于最终 Boss 触发判定。

## 接口变更

| 模块 | 方法/属性 | 类型 | 说明 |
|------|-----------|------|------|
| Pet | `spawnEggAt(position)` | 函数 | 在指定位置放出龙蛋 |
| Pet | `maybeDropEgg(data, position)` | 函数 | 守卫死亡时掉蛋，需主城已到 Lv3 |
| Pet | `ensureEggAvailability()` | 函数 | 主城 Lv3 且已凿穿中级以上矿墙时直接给蛋，不等守卫死 |
| Pet | `hatchPet()` | 函数 | 孵化演出与宠物创建 |
| Pet | `evolvePet()` | 函数 | 进化演出与数值提升 |
| Pet | `pet.evolved` | 状态 | 进化标记 |
| UI | `#egg-tip` | 新增 | 蛋头上的名牌，`#egg-lock` 的子元素，定位与隐藏跟随父元素 |

## 验收标准

- [ ] 中级以上野怪能掉落龙蛋并可拾取。
- [x] 蛋恒定出现在「主城 Lv3 + 凿穿过中级矿」之后不久，孵化稳定落在中级段内（三轮自动流程孵化都在 75–79 秒，锄头 Lv3 在 96 秒之后）。
- [ ] 抱蛋期间无法挖矿和攻击，引导指向孵化台。
- [ ] 孵化台未解锁时有明确提示。
- [x] 蛋在进画面时头上有名牌，说清它是什么、能拿它干什么（实测名牌在屏幕内 92×46，锁环上方）。
- [x] 名牌随锁环一起出画隐藏、拾取即消失，不留残影。
- [ ] 孵化后宠物跟随玩家并自动攻击敌人。
- [ ] 进化台在主城最终形态后可用。
- [ ] 进化演出完成后宠物明显更大更强。
