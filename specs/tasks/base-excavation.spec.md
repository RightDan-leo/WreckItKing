# Task: 基地掘进与前线房间推进

## 背景与动机

当前营地固定在 `z=4`，强化、扩建和龙巢均通过同心扩大同一院落完成。玩家清理更深处的矿墙和敌人后，仍需返回旧营地消费，造成重复通勤，也无法直观看到基地随探索向矿洞深处推进。

## 目标

在不改变四面矿墙、两只石怪、龙蛋和 Boss 主顺序的前提下，将基地改为沿现有矿洞轴线逐室掘进：新矿室清理安全后在当地出现建造格，支付后铺设紧凑营房并保留所有旧房间，当前前缘随之移动到下一面矿墙。

## 空间布局

沿玩家前进的负 Z 方向使用现有矿墙位置组织房间：

- 初始营地房：中心约 `z=4`，首面矿墙坍塌后开放，放置基础营地、工作台和火把。
- 武器房：中心约 `z=-4.8`，利用第二面矿墙坍塌后的空间，放置强化武器设施和壁炉。
- 龙巢房：中心约 `z=-13.8`，利用第三面矿墙坍塌后的空间，放置龙巢、龙蛋设施和前线火把。
- Boss 房：位于最后矿墙后方约 `z=-24`，保持现有 Boss 战区域，不新增矿层。
- 相邻营房间只铺设可供角色和敌人通过的短矿道；矿道两侧保留岩壁、碎石和紫晶，不扩成完整院落。
- 每个营房独立拥有侧墙和前后门洞。建成后所有地板、围墙、火把和设施永久保留。
- 删除“继续扩张”25 金币升级格及前线塔楼，不保留不推动流程的额外建设节点。

## 流程规则

### 首面矿墙与初始营地

1. 开局及首矿引导保持不变。
2. 首面矿墙坍塌后，初始营地房内显示 `camp` 建造格。
3. 金币不足时为白色预览；金币足够时转绿，进入后逐枚支付。
4. 支付完成后铺设初始营地房，并激活第二面矿墙。

### 第一占领房与武器设施

1. 第二面矿墙坍塌后生成第一只石怪。
2. 石怪存活期间，武器房建造格不可见、不可支付。
3. 石怪死亡后，在该矿室当地显示 `weapon` 建造格。
4. 支付完成后铺设武器房、连接矿道和武器设施，升级角色武器，并激活第三面矿墙。

### 第二占领房与龙巢

1. 第三面矿墙坍塌后生成强化石怪。
2. 强化石怪存活期间，龙巢房建造格不可见、不可支付。
3. 强化石怪死亡并掉落龙蛋后，在当地显示 `expand` 建造格。
4. 支付完成后铺设龙巢房、连接矿道和空龙巢。
5. 玩家拾取龙蛋后，只需在当前房间内靠近发光龙巢即可自动安放，不再返回初始房。
6. 龙蛋安放后激活最后矿墙，沿用现有 Boss 护盾与孵化流程。

### Boss 前线与孵化

1. 最后一面矿墙坍塌后生成 Boss，Boss 房保持冷暗战斗区域。
2. Boss 护盾事件触发后，孵化格显示在龙巢房靠近最后矿墙的一侧。
3. 孵化完成后继续使用现有冰龙破盾和 Boss 最终战逻辑。
4. 战斗、扣款和房间建设演出不得同时启动。

## 2026-08-27 修订：建造格防误触与动态碰撞脱困

### 问题

- 前线建造格可能生成在刚结束战斗的角色脚下，造成无意付款和建造。
- 营房墙体与走廊碰撞在升起时立即加入；若玩家位于新碰撞体范围内，会被封在墙体中。

### 方案

- [x] 武器房和龙巢房建造格移入上一间已完成房间，避开战场与主要行进路线
- [x] 建造格保持进入即刻付款，不增加停留确认延迟
- [x] 离开建造格后暂停付款，已付金币保留，再次进入后立即继续
- [x] 若建造格生成在玩家脚下，要求玩家先离开一次，避免生成瞬间自动扣款
- [x] 新建筑碰撞加入后，仅当玩家发生重叠时计算最近安全位置
- [x] 玩家以短促平滑位移脱离到最近侧边空地，并清空移动速度
- [x] 验证正常建造反馈无延迟，且营房墙体升起不会再卡住玩家

## 2026-08-27 修订：房间职责与需求驱动回城

本修订覆盖旧三房推进职责：场景改为“初始武器大厅 + 前进龙蛋房”两间主房，并让设施建设发生在玩家实际遇到能力门槛之后。

### 新流程

1. 首矿坍塌后建设合并的大型第一大厅；初建时没有武器工作台和武器展示。
2. 玩家挖出第一只石怪，用矿镐攻击一次后矿镐损坏，石怪不受伤。
3. 武器建造格在第一大厅出现；玩家返回支付并打造武器，再回到矿室击败第一只石怪。
4. 第一只石怪死亡后，在清空矿室建设第二房间“前进基地”。
5. 玩家继续挖矿并击败强化石怪，拾取掉落的龙蛋。
6. 拾蛋后才在此前建设的前进基地显示龙巢建造格；玩家抱蛋返回、建设龙巢并自动安放。
7. 最后矿墙、Boss 护盾、龙巢孵化与冰龙决战顺序保持不变。

## 2026-08-27 修订：无缝前扩与可选孵龙 Boss 战

上一节的“超长初始大厅 + 独立第二房间”空间理解被本节覆盖。初始基地恢复紧凑尺寸；第一只石怪死亡后的前进基地直接接在原基地前方，形成同一座无内部隔墙的连续基地。

### 最终流程

1. 教学挖矿后建设只有围墙、地面和少量装饰的紧凑初始基地。
2. 第一只石怪被矿镐命中一次后矿镐损坏且怪物不受伤。
3. 返回基地建设武器桌，桌上武器飞入英雄手中；随后快速击败第一只石怪。
4. 石怪死亡后拆除基地前墙，向前连续铺地并延伸外墙，不生成独立房间或连接走廊。
5. 强化石怪使用可预判、可躲避的范围攻击。
6. 强化石怪死亡后掉落龙蛋；拾蛋返回前扩区域建设龙巢并安放。
7. 放蛋后立即显示孵化格，但预计金币不足。
8. Boss 始终可受伤且可单独击杀；攻击将玩家逐渐击退至基地，并通过受击掉币补足孵化费用。
9. 玩家可选择返回孵化冰龙以显著缩短 Boss 战，不再强制开盾或强制返回。
