# Task: 建筑格可视化布局编辑模式

## 背景与动机

建筑格位置目前直接写在 `WreckItKing.html` 中，只能通过截图描述和手工修改坐标反复对齐，难以准确表达“门口”“与龙巢对齐”等空间要求。需要让策划在实际基地边界上直接拖拽建筑格并即时预览结果。

## 目标

增加一个通过 `?editor=1` 开启的轻量布局编辑模式。用户可以俯视查看基地边界，拖拽全部建筑格或输入精确坐标，保存后普通游戏立即使用该布局。

## 变更范围

### 受影响模块

| 模块 | Spec | 代码路径 | 变更类型 | 变更概述 |
|------|------|----------|----------|----------|
| 布局配置 | 本文件 | `WreckItKing.html` 布局常量与建造格创建 | 重构 | 建筑格坐标改为统一配置来源 |
| 编辑模式 | 本文件 | `WreckItKing.html` 初始化、镜头、输入与 UI | 新增 | 增加俯视编辑界面、拖拽和数值输入 |
| 本地保存 | 本文件 | `WreckItKing.html` LocalStorage 接口 | 新增 | 保存、恢复默认并供普通游戏读取 |

### 受影响配置

| 配置 | 变更内容 |
|------|----------|
| `LAYOUT_DEFAULTS`（文件内对象） | 收纳 `camp`、`weapon`、`expand`、`nest`、`dragon`、`end-camp`、`end-hero` 的 X/Z 坐标 |
| LocalStorage `wreck-it-king-layout-v1` | 保存用户编辑后的建筑格布局 |

### 新增文件

无。保持中文版单文件可运行；英文版和历史保留版本不修改。

## 接口变更

### 修改的接口

| 模块 | 方法/属性 | 变更前 | 变更后 | 说明 |
|------|-----------|--------|--------|------|
| Zone | `showFrontierBuildZone(id)` | 坐标写在函数内部 | 从当前布局配置读取坐标 | 普通流程不变 |
| End | `showEndUpgrades()` | 结尾坐标写死 | 从当前布局配置读取 | 与编辑结果一致 |
| Guide | `getGuidePosition()` | 使用多个坐标回退值 | 使用布局配置回退值 | 防止引导与地块分离 |

### 新增的接口

| 模块 | 方法/属性 | 类型 | 说明 |
|------|-----------|------|------|
| Layout | `loadLayoutConfig()` | 函数 | 合并默认值与已保存布局 |
| Layout | `saveLayoutConfig()` | 函数 | 将当前编辑结果写入 LocalStorage |
| Layout | `resetLayoutConfig()` | 函数 | 恢复默认布局 |
| Editor | `initLayoutEditor()` | 函数 | 创建编辑器标记、面板和俯视镜头 |
| Editor | `updateLayoutEditorPointer(...)` | 函数 | 将拖拽指针投射到地面并更新 X/Z |

## 编辑器交互规格

- URL 添加 `?editor=1` 后进入编辑模式，不启动正常战斗流程。
- 镜头默认覆盖两段基地并保持俯视；隐藏矿体和敌人，显示基地地板、外墙、门洞及建筑设施参照。
- 在场景空白处拖拽可平移镜头，滚轮或面板按钮可缩放，WASD / 方向键可连续移动，并可一键恢复默认居中视角。
- 同时显示所有建筑格；重叠的格子可通过右侧列表选择。
- 单击列表或地面格只选中目标，不改变其位置；超过拖拽阈值后才实时更新位置，并保持抓取点偏移。
- 右侧面板显示选中项名称、X、Z；数字输入支持精确微调。
- 地面启用 `0.1` 单位吸附，按住 Shift 时改为 `0.5` 单位吸附。
- 提供“保存布局”“恢复默认”“复制 JSON”按钮。
- 保存后刷新普通 URL 即可使用新坐标；恢复默认会清除本地覆盖。
- 编辑器只编辑坐标，不允许触发付款、建造回调或游戏阶段推进。

## 实施计划

- [x] 增加编辑模式检测、基地参照显示和固定俯视镜头
- [x] 创建建筑格编辑标记、选择列表及 X/Z 数值输入
- [x] 实现鼠标/触控拖拽、网格吸附和重叠格选择
- [x] 实现编辑镜头拖拽平移、键盘移动、缩放和居中复位
- [x] 实现 LocalStorage 保存、恢复默认和复制 JSON
- [x] 验证编辑模式不推进游戏，普通模式读取保存布局且完整流程不受影响

## 验收标准

- [x] `?editor=1` 能显示完整基地和所有可编辑建筑格
- [x] 任意格子可拖拽或通过输入框修改 X/Z
- [x] 单击建筑格只切换选中状态，不会让建筑格跳到指针位置
- [x] 镜头可自由平移和缩放，且不干扰建筑格拖拽
- [x] 保存并刷新普通游戏后，实际建筑格使用编辑后的坐标
- [x] `nest` 与 `dragon` 即使重叠也能分别选择和编辑
- [x] 恢复默认后所有坐标回到代码内默认值
- [x] 编辑模式不会扣金币、刷怪或触发建造
- [x] 页面无新增运行时错误，桌面与触控拖拽均可使用

## 风险与注意事项

- 浏览器页面不能在无后端的情况下直接改写源码，因此第一版使用 LocalStorage 保存，并提供 JSON 复制用于固化配置。
- 编辑器标记与正常游戏建造格必须分离，避免编辑操作误触现有付款逻辑。
- 现有游戏为单 HTML 文件，不为本功能引入 Vite 或完整项目迁移。

## 备注

- 第一版只编辑建筑格坐标；矿体长度、怪物出生点和装饰物作为后续扩展。
