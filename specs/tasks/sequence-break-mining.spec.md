# Task: 逃课挖穿路线

## 目标

把“无视第一只怪继续挖矿”保留为正式技巧路线。正常路线可击杀第一只怪提前解锁前进基地；逃课路线可不杀第一只怪，但必须继续深入并挖完整面强化石怪矿墙，随后同样解锁前进基地。强化石怪和 Boss 的攻击也能损坏尚未升级的基础矿镐，为深入逃课提供风险。

## 推进路线

### 正常路线

1. 第一只怪显形并攻击玩家。
2. 玩家升级武器并击杀第一只怪。
3. 立即解锁前进基地建造区。
4. 基地完成后继续强化矿与后续流程。

### 逃课路线

1. 第一只怪显形后，玩家不与其战斗并继续向深处挖掘。
2. 玩家挖完整面强化石怪矿墙。
3. 即使第一只怪仍存活，也立即解锁前进基地建造区。
4. 第一只怪和强化石怪继续遵守追击范围并保持威胁。
5. 玩家可稍后回头击杀第一只怪，但不得重复解锁或回退阶段。

## 前进基地解锁

- 抽取幂等入口 `unlockForwardBase(reason)`。
- 以下任一条件首次达成时解锁：
  - 第一只怪死亡。
  - 强化石怪矿墙完全清除。
- 解锁时激活现有 `expand` 建造区。
- 若建造区已激活或已完成，后续触发只结算原事件，不重复显示、重复提示或修改阶段。
- 第一只怪在逃课路线后死亡时只保留掉落，不把阶段强制改回 `EXPAND`。
- 若断镐升级正在进行，解锁建造区但不覆盖 `WEAPON` 阶段；升级完成后恢复最深有效进度。

## 后续怪物断镐

- 第一只怪重砸、强化石怪扇形攻击和 Boss 预警攻击命中时都可触发断镐。
- 仅 `weaponLevel < 2` 且矿镐尚未损坏时生效。
- 已升级武器不再损坏。
- 断镐只暂停玩家自动攻击并引导返回武器大厅，不停止怪物攻击。
- `breakPickaxeOnGolem(source)` 记录断镐前阶段和攻击来源。
- 武器升级完成后恢复断镐前的最深有效阶段，不固定回到 `FIRST_GOLEM`。

## 深层阶段恢复

`finishWeaponEquip()` 按当前世界状态恢复：

1. 若 Boss 已出现且存活，恢复 Boss 阶段。
2. 若前进基地已解锁但未完成，恢复 `EXPAND`。
3. 若强化石怪矿墙已清除且强化石怪存活，恢复 `STRONG_GOLEM`。
4. 若仍处于强化矿挖掘，恢复 `MINE_STRONG`。
5. 其他情况回退到断镐前记录阶段或 `FIRST_GOLEM`。

恢复只修改当前引导阶段，不复活矿墙、怪物或重复生成奖励。

## 前进基地完成兼容

- `completeExpand()` 先检查强化矿墙与强化石怪的实时状态。
- 强化矿墙仍存活时，进入 `MINE_STRONG` 并激活矿墙。
- 强化矿墙已清除且强化石怪存活时，进入 `STRONG_GOLEM`。
- 强化石怪已死亡且龙蛋已生成时，保持 `EGG`，不回退。
- 不重新激活已清除矿墙。

## 变更范围

- `WreckItKing.html` 第一只怪死亡回调：改用幂等基地解锁。
- `WreckItKing.html` 强化矿墙清除回调：增加逃课路线基地解锁。
- `WreckItKing.html` `breakPickaxeOnGolem()` / `finishWeaponEquip()`：记录并恢复深层阶段。
- `WreckItKing.html` 强化石怪与 Boss hazards：命中基础矿镐时触发断镐。
- `WreckItKing.html` `completeExpand()`：根据实时世界状态继续流程。

## 验收标准

- [x] 击杀第一只怪仍能立即解锁前进基地。
- [x] 第一只怪存活时，挖完整面强化矿墙也能解锁前进基地。
- [x] 两个条件先后达成只解锁一次，不发生阶段回退。
- [x] 强化石怪扇形和 Boss 攻击能打坏基础矿镐。
- [x] 升级武器不会被后续怪物再次损坏。
- [x] 深层断镐升级完成后不会固定返回第一只怪阶段。
- [x] 前进基地完成后不会重新激活已清除的强化矿墙。
- [x] 仍存活怪物继续按追击范围战斗。
- [x] 原有金币、龙蛋、Boss 和最终奖励流程保持正常。

## 风险与注意事项

- `phase` 不能再作为世界进度的唯一事实来源；恢复阶段必须检查矿墙、怪物、建造区和龙蛋实际状态。
- 解锁入口必须幂等，避免首怪死亡和矿墙清除交错触发。
- 断镐不能覆盖更深层已达成进度。
- 逃课路线不创建安全区，建造前进基地时仍可能受到怪物攻击。
