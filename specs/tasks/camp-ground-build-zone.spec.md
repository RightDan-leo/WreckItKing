# Task: 全流程地面建造与升级格

## 背景与动机

当前建营、强化、安放龙蛋、孵龙和结尾升级都使用圆形光圈与浮空 HTML 标签，容易被玩家理解为需要点击的按钮。目标参考使用贴合地面的建造格，直接在地面表达操作类型与金币消耗。

## 目标

将全流程所有消费区域统一改成无浮空标签的方形地面建造/升级格，通过对应图标、金币费用和入场反馈，让玩家理解“走进地块会自动消耗金币执行当前操作”。

## 视觉与交互规格

- `camp`、`weapon`、`expand`、`dragon`、`end-camp`、`end-hero` 全部改成贴地方格。
- 操作格边长约 `3.2`，与触发范围基本一致。
- 默认使用深色半透明底、白色虚线边框和对应操作图标。
- 图标按类型区分：建营、强化装备、扩建安蛋、孵龙、强化营地、升级英雄。
- 地面显示黄色金币图标和动态支付进度；进入前为 `0 / 费用`，支付时逐枚增长到目标值。
- 所有消费区域均不创建或显示浮空 HTML 标签。
- 金币足够时，地块边框偏绿并播放轻微呼吸；金币不足时保持白色。
- 玩家进入地块后自动逐枚支付，保留现有金币飞入地块反馈。
- 支付过程中不增加点击按钮、手指点击提示或确认操作。
- 支付完成后地块隐藏，继续使用各阶段现有完成动画和流程。
- 顶部目标文案根据阶段分别显示：
  - 建营：「走进建造地块，建设营地」
  - 强化：「走进强化地块，升级营地与装备」
  - 扩建：「走进扩建地块，扩建营地并安放龙蛋」
  - 孵龙：「走进孵化地块，孵化飞龙」
  - 结尾：「走进升级地块，继续强化」

## 2026-08-26 修订：支付进度、提前预览与遮挡修复

本节覆盖上方“只显示静态费用、到阶段后才创建地块”的实现：

- 所有地块显示 `已支付 / 总费用`，例如建营初始显示 `0 / 10`。
- 玩家进入后数字随逐枚扣款快速递增，金币总数与背包金币同步减少，每枚金币继续飞向地块。
- 单枚支付间隔调整到肉眼可读但仍快速的节奏，10 金币约 0.6–0.8 秒完成。
- 完成当前基地建设/升级后，立即显示下一阶段地块作为预览：
  - 建营完成 → 提前显示强化地块。
  - 强化完成 → 提前显示扩建安蛋地块。
  - 安放龙蛋完成 → 提前显示孵龙地块。
- 预览地块保持白色/未激活状态，只用于展示下一目标；未到对应阶段时不能扣款。
- 对应阶段解锁后，预览地块转为可支付状态，金币足够时变绿。
- 重新安排扩建、孵龙及结尾地块位置，确保不被壁炉、工作台、孵化台、龙蛋或围墙遮挡。

## 2026-08-26 修订：金币软门槛与按需提示

本节覆盖“地块必须等指定 `PHASE` 才能支付”和“顶部目标框常驻”的实现：

- 建造与强化地块是否可支付，主要由当前金币是否达到剩余费用决定，不再依赖对应剧情阶段字符串硬解锁。
- 地块仍按建造成果依次出现，避免玩家同时看到全部升级：
  - 初始建营格从开局即已生成，穿过首层矿后可直接看到；金币达到 10 后自动转为可支付状态。
  - 建营完成后显示强化格；强化完成后显示扩建安巢格。
  - 金币不足时地块保持白色预览，足够后变绿，玩家进入即可支付。
- 与实体强关联的操作保留必要条件，防止流程断裂：
  - 安放龙蛋仍要求玩家已经携带龙蛋。
  - 孵化仍要求龙蛋已经安放，并在 Boss 护盾事件后执行。
  - 这些条件只保护龙蛋/Boss 演出，不再用普通 `PHASE` 判断限制营地建造和强化。
- 删除顶部 `#objective` 提示框及对应 CSS、DOM 和更新逻辑，不保留常驻目标 UI。
- 需要文字提醒的关键节点统一使用现有 `toast` 样式，与“获得龙蛋”“双手被龙蛋占满”“装备太弱”等反馈保持一致。
- 只在玩家需要重新定向或操作被阻止时弹出短时提醒：首次金币足够建营、击败怪物后返回营地、携带龙蛋无法战斗、Boss 护盾无法击破、结尾升级。
- 挖矿、战斗、建造完成等已经由场景、地面格或特效清楚表达的常规目标不重复弹出引导。
- 开局手势教程、地面费用、金币 HUD、屏外方向箭头和龙蛋拾取进度环保持现有职责。

## 2026-08-26 修订：扩建与龙蛋流程解耦

截图中的地块是“扩建安巢”地块。此前实现错误地把“携带龙蛋”作为扩建支付条件，导致玩家已有 14 金币时地块仍保持 `0 / 10` 且不可建造。本节覆盖上方对扩建安全条件的定义：

- 扩建安巢属于建筑建设，只由金币数量限制；地块出现后，金币达到剩余费用即可支付，不要求玩家已经取得或携带龙蛋。
- 提前完成扩建时立即建设三级营地与空龙巢，但不切换挖矿/怪物/Boss 阶段。
- 如果支付扩建时已经携带龙蛋，沿用现有飞入龙巢的安放动画。
- 如果扩建早于获得龙蛋，玩家后续抱蛋返回营地并靠近龙巢时自动触发安放动画。
- 孵龙仍要求龙蛋已安放且 Boss 护盾事件已触发；该条件属于角色/演出条件，不属于建筑建设门槛。

- [x] 将扩建完成与龙蛋安放拆成两个独立步骤
- [x] 扩建提前完成时保持当前战斗阶段，不跳过第二只怪或第四层矿
- [x] 增加携蛋返回已建龙巢附近时的自动安放检测

## 2026-08-26 修订：放蛋与孵化视觉分阶段

当前扩建完成后会立即显示左下角孵化付费框。玩家抱蛋回营时，付费框和右侧龙巢同时可见，容易误认为必须先走进左下角框才能放蛋。本节调整两个动作的视觉顺序：

- 营地扩建完成但龙蛋尚未安放时，不显示孵化付费框。
- 玩家携带龙蛋时，右侧龙巢显示蓝色呼吸光圈、半透明幽灵蛋和轻微上浮动画，成为场景中唯一的放蛋目标。
- 拾取龙蛋后的短时提醒改为「将龙蛋带回发光龙巢」。
- 玩家靠近发光龙巢后继续沿用自动安放和飞入动画。
- 龙蛋安放完成后，再显示左下角孵化付费框作为下一阶段预览。
- 孵化框图标由蛋壳/裂纹改成冰龙头或冰焰轮廓，避免与“放蛋”语义重复。
- Boss 护盾触发且金币足够后，孵化框才转为绿色可支付状态。

### 修订实施计划

- [x] 为龙巢增加仅在携蛋状态显示的蓝色呼吸光圈与幽灵蛋
- [x] 将拾蛋提醒改为「将龙蛋带回发光龙巢」

## 2026-08-27 修订：保留连升体验并增加后续扩张目标

为了同时保留“强化装备后连续扩建两次”的爽感，并让玩家在不知道龙蛋存在的情况下自然继续挖矿，新增一个真实可支付的后续营地扩张目标：

- 保留当前 `强化装备 10 → 扩建营地 10` 的连续升级与连续建造动画。
- 现有扩建完成后，立即显示新的“继续扩张营地”地块，费用为 `0 / 25`。
- 新地块使用瞭望塔/城墙旗帜图标，不出现龙蛋、龙巢或孵化语义。
- 玩家金币不足时会自然继续挖矿；第二只怪死亡后，龙蛋仍作为未提前剧透的意外掉落。
- 继续扩张是可真实完成的金币软门槛，不使用不可支付的假预览：
  - 支付完成后营地扩展到第四阶段。
