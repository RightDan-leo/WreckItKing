# A 版低级矿区扩城

目的：减少开采中、高级矿后返回升级设施的折返距离。

- 仅 A 版启用。主城至少 Lv.3，低级矿剩余格数为 0 且爆破动画结束，自动建成一次前沿广场。支持先清矿或先升级，不额外收费，不清除仍存在的矿石。
- 广场位于低级矿原址，由道路连接老城。中央保留通行，锻造建筑、孵化巢及民房放两侧。
- 城建、锄头、武器、孵化地贴迁移至新区，保留原付款对象及部分付款，每种设施只有一个入口。锄头最后一级仍在同一新区位置。
- 孵化巢的视觉、碰撞、龙蛋终点同步迁移；已落巢或正在投放的蛋也同步处理。
- 新区服务区域禁止敌人进入；中级矿前保留战斗空间。
- B 的固定主城、C 的区块扩城不改变。

验收：既有 ABC 全流程回归；A 两种触发顺序、部分付款迁移、一次性建造、通道和地贴碰撞探测、桌面及手机截图。专项场景为 `scripts/a-frontier-scenario.js`。
