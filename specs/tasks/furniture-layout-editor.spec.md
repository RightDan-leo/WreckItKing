# Task: 建筑编辑器家具位置调整

## 背景与动机

营地家具位置目前直接写在 `WreckItKing.html` 的场景创建代码中，建筑格编辑器只能调整建造格，家具仍需手工修改坐标。需要在现有编辑模式中直接选择、拖拽和保存家具位置。

## 目标

扩展 `?editor=1` 布局编辑器，使用户能在建筑格与家具之间切换，调整家具的 X/Z 坐标。保存后普通游戏及相关特效、交互目标统一使用新位置。

## 首版可编辑对象

| ID | 面板名称 | 联动内容 |
|----|----------|----------|
| `fireplace` | 壁炉 | 壁炉主体与火光 |
| `torch-room-1` | 前厅火把 | 火把与火焰动画 |
| `torch-room-2-left` | 后厅左火把 | 火把与火焰动画 |
| `torch-room-2-right` | 后厅右火把 | 火把与火焰动画 |
| `workbench` | 工作台 | 工作台、武器展示与建造特效 |
| `hatch-platform` | 龙巢平台 | 平台、引导圈、放蛋目标与建造特效 |

首版只编辑水平面 X/Z 坐标；高度、朝向、缩放和新增/删除家具不在本次范围内。

## 接口变更

### 修改的接口

| 模块 | 方法/属性 | 变更前 | 变更后 | 说明 |
|------|-----------|--------|--------|------|
| Layout | `saveLayoutConfig()` | 只保存建筑格 | 同时保存建筑格和家具 | 面板仍使用一个保存按钮 |
| Layout | `resetLayoutConfig()` | 只恢复建筑格 | 同时恢复建筑格和家具 | 清除两类本地覆盖 |
| Layout | `copyLayoutConfig()` | 复制建筑格对象 | 复制含 `zones`、`furniture` 的对象 | 便于固化全部布局 |
| Camp | 家具创建函数 | 接收写死的世界坐标 | 使用家具配置创建可整体移动的根组 | 保持视觉结构不变 |

### 新增的接口

| 模块 | 方法/属性 | 类型 | 说明 |
|------|-----------|------|------|
| Furniture | `loadFurnitureConfig()` | 函数 | 合并默认家具位置与本地保存值 |
| Furniture | `getFurniturePosition(id, y)` | 函数 | 返回家具或联动逻辑使用的世界坐标 |
| Editor | `selectFurnitureEditorItem(id)` | 函数 | 只选中家具，不立即改变位置 |
| Editor | `setFurnitureEditorPosition(id, x, z)` | 函数 | 更新家具根组、手柄与面板坐标 |

## 编辑器交互规格

- 面板将建筑格与家具分组显示，任一时刻只选中一个对象。
- 家具在场景中显示容易点击的编辑手柄；实际家具保持可见，方便对照房间边界。
- 单击家具、编辑手柄或列表项只切换选中状态，不改变坐标。
- 拖动超过 4px 后才移动家具，并保持抓取点偏移，避免选中时跳位。
- 家具拖拽默认按 0.1 单位吸附，按住 Shift 时按 0.5 单位吸附。
- X/Z 数字输入、镜头平移、镜头缩放及居中功能同时适用于家具编辑。
- 保存后刷新普通游戏，家具、火焰、武器建造特效、龙巢引导和放蛋目标使用保存坐标。

- [x] 验证家具选中不跳位、拖拽偏移正确且普通游戏联动目标一致

## 验收标准

- [x] 编辑器中能通过列表或场景选中全部 6 组家具
- [x] 单击家具只选中，X/Z 坐标保持不变
- [x] 家具可拖拽或通过数字输入精确调整，建筑格编辑不受影响
- [x] 保存并刷新后，普通游戏中的家具使用新坐标
- [x] 火焰跟随火把，武器展示跟随工作台，蛋与引导跟随龙巢平台
- [x] 恢复默认可同时还原建筑格和家具位置
- [x] 编辑模式不触发付款、建造、刷怪或阶段推进
- [x] 页面无新增运行时错误，桌面和触控拖拽均可使用

## 风险与注意事项

- 组合家具必须使用独立根组移动，避免只移动主体而遗漏火焰、展示物或引导对象。
- 龙巢平台包含实际交互目标；所有距离检测、引导和特效必须从同一家具配置读取。
- 家具存储使用独立版本键，避免破坏已经保存的建筑格布局。
- 家具可移出房间边界属于编辑自由；首版不自动限制到所属房间。

## 备注

- 后续如需调整朝向，可在家具配置中追加 `rotationY`，不影响首版坐标格式。
