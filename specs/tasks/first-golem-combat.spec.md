# Task: 第一只石怪挖矿阻断战

## 背景与动机

第一只石怪在容身洞穴清空后已经显形并显示血条，但战斗激活仍等待整面矿墙坍塌，造成怪物完全露出后静止不动。第一只怪应在显形落地后立即成为威胁，用一招带预警的重砸持续干扰挖矿并打坏矿镐，同时保持玩家原有挖矿目标，不发生莫名其妙的自动转向。

## 目标

第一只普通石怪完成显形落地后立即进入战斗：主动接近正在挖矿的玩家，以单一、明显蓄力、范围较大且较难躲开的重砸攻击阻断挖矿；命中后损坏矿镐并引导玩家升级武器。所有伤害必须来自预警完成后的攻击判定，身体接触不造成伤害。

## 已确认流程

1. 矿墙挖掘到足以清空石怪容身洞穴。
2. 石怪从剪影切换为正式外观，原地起身并显示头顶血条。
3. 石怪眼睛变亮，立即进入战斗，不吼叫。
4. 玩家保持当前矿墙挖掘锁定，不自动切换攻击石怪。
5. 石怪接近矿墙前的玩家并反复使用“阻断重砸”。
6. 重砸命中玩家后造成少量伤害、击退并损坏矿镐。
7. 矿镐损坏后石怪仍继续追击和使用重砸，维持撤退压力。
8. 玩家或石怪离开以出洞原位为中心的追击范围后，石怪取消攻击并返回原位；玩家重新进入范围后恢复追击。
9. 武器升级完成后石怪成为玩家自动攻击目标。
10. 玩家使用升级武器约三击击败石怪，随后继续原有基地扩建流程。

## 攻击规格：阻断重砸

- 石怪只有这一种攻击。
- 身体接触不造成伤害。
- 进入约 `3.0` 单位攻击范围后停步蓄力。
- 蓄力总时长约 `0.7s`。
- 地面显示红色圆形预警，默认半径约 `3.0`。
- 预警前 `0.35s` 跟随玩家位置，最后 `0.35s` 锁定落点。
- 蓄力时双臂抬起、紫色眼睛增强，不播放吼叫。
- 攻击生效时砸地、产生石屑、镜头震动和明确命中音效。
- 命中造成约 `6` 点伤害和朝远离石怪方向的击退。
- 命中必定损坏未升级矿镐。
- 无论命中或躲开，石怪完成约 `0.9s` 收招后再次接近并尝试攻击；损坏矿镐不再中止攻击循环。
- 攻击蓄力阶段可以在后续系统中被强控制打断；本任务不新增玩家打断手段。

## 追击范围与返回规则

- 石怪完成显形时记录当前位置为 `homePosition`。
- 战斗领地以 `homePosition` 为中心，默认追击半径约 `7` 单位。
- 玩家离开追击半径，或石怪自身到达领地边界时，立即取消未生效的重砸预警并进入 `returning`。
- `returning` 状态不追击、不攻击，按约 `2.2` 速度返回 `homePosition`。
- 玩家仍在领地外时，石怪回到原位后保持等待。
- 玩家重新进入约 `6.5` 单位的重激活半径后，石怪恢复追击；使用略小的重激活半径避免边界抖动。
- 返回逻辑由三类怪物共享的追击范围系统执行；本规格保留第一只石怪的专属范围数值。

## 自动攻击与阶段规则

- 石怪显形后加入敌人 AI 更新，但在矿镐损坏前不加入玩家的 `targets`。
- 玩家继续自动攻击当前矿墙，不因石怪接近而切换目标。
- 矿墙保持可挖，进度不重置。
- 矿镐损坏后暂停玩家自动攻击并进入现有武器升级引导。
- 矿镐损坏不改变石怪攻击状态；玩家必须主动撤出追击范围。
- 武器升级完成时，把仍存活的第一只石怪加入玩家 `targets`；石怪是否追击仍由领地范围决定。
- 不再使用“玩家先攻击石怪导致矿镐损坏”作为主触发方式。

## 变更范围

- `WreckItKing.html` `MINE_DEFAULTS["mine-golem"].combat`：集中配置速度、攻击范围、蓄力、跟随、预警半径、伤害、收招、追击半径、重激活半径与返回速度。
- `WreckItKing.html` 剪影显形交接：落地后激活第一只石怪 AI。
- `WreckItKing.html` 第一只石怪数据：保存出洞原位，并增加追击、蓄力、收招、返回和原位等待状态。
- `WreckItKing.html` `updateEnemies()`：为第一只石怪增加独立攻击状态机，移除无预警接触直伤。
- `WreckItKing.html` hazards：增加会先跟随、后锁定的重砸预警。
- `WreckItKing.html` `breakPickaxeOnGolem()`：只处理断镐与升级引导，不再停止石怪攻击。
- `WreckItKing.html` `finishWeaponEquip()`：升级完成后把石怪加入玩家目标。

## 状态流转

1. `dormant`：位于矿墙剪影阶段。
2. `emerging`：正式外观原地起身。
3. `chasing`：接近玩家，不造成接触伤害。
4. `windup`：停止移动、抬臂并显示预警。
5. `recovery`：砸地后收招，暂时不能移动或再次攻击。
6. `returning`：超出领地后取消攻击并返回出洞原位。
7. `leashed`：已回到原位，等待玩家重新进入重激活半径。
8. `combat`：升级后允许玩家自动攻击；石怪仍遵守追击范围。
9. `dead`：沿用现有死亡、掉币和阶段推进。

- [x] 重砸命中时造成少量伤害、击退并损坏矿镐。
- [x] 移除矿镐损坏后的守卫状态，让石怪继续攻击。
- [x] 记录出洞原位并实现追击边界、返回和重激活状态。
- [x] 超出追击范围时取消尚未生效的重砸预警。
- [x] 武器升级后恢复石怪战斗并加入玩家攻击目标。
- [x] 验证断镐后持续攻击、撤出范围、回到原位、重新进入和升级反击完整流程。

## 验收标准

- [x] 第一只石怪完全显形并落地后立即开始主动接近玩家。
- [x] 石怪所有攻击都有可见预警和蓄力，不存在接触直伤或瞬间扣血。
- [x] 石怪显形不会让玩家自动攻击从矿墙切换到石怪。
- [x] 玩家可以继续挖矿，但重砸会迫使玩家移动并降低连续挖矿效率。
- [x] 重砸较难躲避，但在锁定后立即全速离开预警区仍有机会躲开。
- [x] 重砸命中必定损坏未升级矿镐。
- [x] 矿镐损坏后石怪继续使用带预警重砸，不会立刻停止战斗。
- [x] 玩家撤出追击范围后石怪停止攻击并回到出洞原位，不会追进基地。
- [x] 石怪回到原位后不会在边界反复来回，玩家重新进入范围才恢复追击。
- [x] 武器升级后玩家能自动攻击石怪，并在约三击内击败。
- [x] 石怪死亡后继续原有前进基地建设流程。

## 风险与注意事项

- 第一只石怪不能复用普通怪现有的无预警 `damagePlayer()` 分支。
- 预警跟随时间过长会成为不可躲必中；必须保证至少约 `0.35s` 的锁定后逃离窗口。
- 石怪激活与玩家可攻击必须拆开，避免显形瞬间抢走矿墙目标。
- 追击范围必须以固定 `homePosition` 为基准，不能随石怪移动而漂移。
- 进入返回状态时必须清理该石怪尚未爆发的 hazard，避免已脱战仍在远处结算攻击。
- 追击与重激活使用不同半径，避免玩家位于边界时石怪频繁切换状态。
