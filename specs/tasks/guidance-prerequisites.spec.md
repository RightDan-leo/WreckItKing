# 引导前置与执行条件

修复场景：A/B 主城 Lv.3、锄头 Lv.1、升级材料不足（例如 3/4）时，孵化台已出现但龙蛋仍在无法凿开的中级矿后。

- 材料不足先指向尚有该品质宝石且当前可采的矿段；不能先指龙蛋。
- 材料充足后指锄头台；预算按总价减去已交材料计算。
- 龙蛋及设施目标要检查路途中是否跨越当前锄头无法破坏的矿层；清空的矿层不阻挡。C 使用已开放区块边界。
- 缺钻石时只选当前可到达、可攻击的已出土守卫。
- 不指向隐藏、已完成或尚不满足付款条件的地贴；需要离场再进入时引导走出地贴，避免中心原地等待。
- 删除无可采矿时强行指向缺材料、锁定设施的兜底。
- 保留携蛋返巢、进化、怪潮、献祭、破封的正常推进顺序。

验证：`scripts/guidance-scenario.js` 复现 A/B 缺一颗材料、足额、部分付款、升级后蛋可达及地贴重入；`verify:playtest` 覆盖 ABC 全流程、新区两种顺序、C 手动付款与孵化流程。
