# Task: 三类矿墙怪物剪影预示系统

## 背景与动机

当前第一只石怪、强化石怪和 Boss 都隐藏到对应矿墙坍塌后才出现，玩家在挖掘过程中无法提前感知墙后的威胁。参考画面会在紫色矿墙内部展示怪物黑色轮廓和发光眼睛，使挖矿阶段同时承担敌人预告与气氛营造。

## 目标

建立一套由三类怪物共用的矿墙剪影系统：随着挖掘进度推进，怪物轮廓在墙内逐渐显现；当怪物完整包围盒周围形成足够容身的洞穴时，怪物在清空洞穴的原始位置切换为正式外观并完成短暂起身。三类怪物均在起身落地后交接到各自正式战斗实体或 AI，不再等待整面矿墙坍塌。

## 已确认设计

### 适用对象

- 第一只普通石怪。
- 第二只强化石怪。
- 最终独眼 Boss。

### 进度定义

- 挖掘进度以 `1 - remainingCells / totalCells` 计算。
- `0%` 表示矿墙完整，`100%` 表示矿墙清除。
- 默认在约 `35%` 时开始出现极淡轮廓。
- 默认在约 `45%` 时清楚看到轮廓和眼睛。
- 全局挖掘进度只控制剪影渐显，不再控制剪影结束。
- 剪影结束由怪物完整包围盒及安全余量内是否仍有矿块重叠决定。
- 容身洞穴清空后切换正式外观，并在约 `0.4s` 内原地起身；不得沿矿道方向瞬移或移动到基地门口。矿墙其他位置继续保留并允许挖掘。
- 普通石怪、强化石怪和 Boss 都在显形落地后立即激活；各自攻击规则仍由对应战斗系统负责。

### 视觉规则

- 剪影位于矿墙内部，不得表现成贴在墙面的图标或 UI。
- 使用与正式怪物一致的基础轮廓，避免剪影与出场实体造型不一致。
- 身体呈接近黑色的紫黑轮廓，保留低透明度和轻微紫色边缘光。
- 眼睛保持清晰的紫色自发光，不添加吼叫或文字提醒。
- 矿墙中央对应区域允许轻微透光，以接近“隔着紫色晶体看到墙后生物”的效果。
- 剪影只做缓慢呼吸、轻微重心摆动或头部偏转，不执行攻击动作。
- 剪影必须被对应矿墙范围约束，不应穿过相邻矿墙、营地建筑或显示在墙体轮廓之外。
- 当剪影正面已没有矿块遮挡时，不允许继续以剪影材质悬浮在矿外。
- 正式外观交接必须在同一帧完成：先关闭剪影材质，再在清空洞穴原位显示正式材质并开始起身动画。
- 正式外观必须恢复正常受光、投影和清晰眼睛，不能继续呈现紫黑剪影质感。
- 剪影阶段不显示血条；怪物迈出洞口并落地时淡入头顶红色血条。
- 普通石怪和强化石怪使用世界空间头顶血条；Boss 继续使用现有屏幕顶部大型 HUD。

### 差异化表现

- 普通石怪：标准体型，双紫眼，动作幅度最小。
- 强化石怪：轮廓更宽更高，双眼和胸口核心缓慢脉动。
- Boss：明显更大的上半身与单眼轮廓，占据矿墙中心主要区域，单眼亮度高于石怪。

## 变更范围

### 受影响模块

- `WreckItKing.html` `MINE_DEFAULTS`：为三面怪物矿墙增加剪影显示参数。
- `WreckItKing.html` `createLinearMineGates()`：把对应怪物预览与矿墙关联。
- `WreckItKing.html` `createGolem()` / `createBossPreview()`：复用正式造型创建剪影外观。
- `WreckItKing.html` `createMineGate()` / `chipMineLocally()`：根据统一挖掘进度更新剪影状态。
- `WreckItKing.html` 动画循环：驱动低频待机和眼睛/核心脉动。
- `WreckItKing.html` 局部挖掘与矿墙坍塌流程：检测剪影正面遮挡，在局部暴露时交接正式外观，并保留最终坍塌兜底。

### 建议配置

```javascript
silhouette: {
  enabled: true,
  revealStart: 0.35,
  revealFull: 0.45,
  opacity: 0.72,
  eyeIntensity: 1,
  scale: 1,
  clearanceWidth: 3.2,
  clearanceHeight: 3.8,
  clearanceDepth: 2.8,
  emergeDuration: 0.4,
  offsetX: 0,
  offsetY: 0,
  offsetZ: 0
}
```

强化石怪使用更大的局部净空区域，Boss 使用最大的局部净空区域。Boss 和强化石怪可覆盖 `scale`、`opacity`、眼睛/核心亮度及位置偏移。配置仅管理剪影视觉与外观交接，不管理敌人战斗数值。

## 接口设计

### 新增职责

- `attachMonsterSilhouette(gate, preview, options)`：把预览实体绑定到矿墙并保存配置。
- `updateMonsterSilhouette(gate, progress, elapsed)`：根据挖掘进度更新可见性、透明度和待机表现。
- `isMonsterSilhouetteExposed(gate, state)`：检查怪物完整包围盒加安全余量的三维区域内是否仍存在矿块。
- `revealMonsterFromSilhouette(gate)`：容身洞穴形成时在原位切换正式外观并启动起身动画。
- `updateMonsterAppearanceHandoff(gate, dt)`：驱动约 `0.4s` 的原地起身，在完成时淡入头顶血条并调用怪物的 `onAppearanceSettled` 战斗交接。
- `removeMonsterSilhouette(gate)`：正式怪物出现或矿墙销毁时清理剪影资源。
- `getMineExcavationProgress(gate)`：统一返回 `0–1` 的挖掘进度。

具体函数名允许实现时根据单文件结构调整，但必须保持“绑定、更新、局部暴露检测、外观交接、清理、统一进度”六项职责。

## 状态流转

1. `hidden`：未达到 `revealStart`，剪影不可见。
2. `fading-in`：从 `revealStart` 到 `revealFull`，身体和眼睛逐渐显现。
3. `visible`：达到 `revealFull`，保持墙内待机与轻微脉动。
4. `exposed`：怪物完整包围盒及安全余量内不再有矿块重叠。
5. `emerging`：同一实体在清空洞穴原位切回正式材质并完成轻微上升起身。
6. `revealed`：怪物落地并立即进入战斗，普通/强化石怪头顶血条淡入；其他矿块保持可挖。

倒退挖掘进度不属于现有玩法；无需支持从 `visible` 恢复到 `hidden`。

## 验收标准

- [x] 三面怪物矿墙都能在挖掘过程中看到对应怪物剪影。
- [x] 剪影在约 `35%` 挖掘进度开始渐显，在约 `45%` 时清楚可辨。
- [x] 普通石怪、强化石怪和 Boss 的轮廓、眼睛数量及体型可明显区分。
- [x] 剪影看起来位于紫色矿墙内部，不是屏幕 UI 或墙面贴花。
- [x] 剪影渐显阶段不会改变矿墙可挖状态、攻击目标、敌人 AI、伤害或阶段推进。
- [x] 正式怪物出现时画面中不存在重复剪影。
- [x] 重开游戏后剪影状态正确重置，不残留旧实体或材质状态。
- [x] 自定义矿体尺寸和 `spawnZ` 后，剪影仍保持在对应矿墙内部。
- [x] 怪物正面仍有矿块时保持墙内剪影，局部矿块清空后立即显示正式外观。
- [x] 正式外观出现后，周围未挖矿块继续存在且保持可挖。
- [x] 不再出现矿块已经挖空、剪影却悬浮在矿外的画面。
- [x] 正式怪物出现前，其完整身体周围已形成足够大的容身洞穴。
- [x] 正式怪物在约 `0.4s` 内于清空洞穴原位起身，不与剩余矿块重叠。
- [x] 普通和强化石怪落地后显示满血头顶血条，剪影阶段不显示血条。
- [x] 正式外观具有正常受光和阴影，不再看起来像换色后的剪影。
- [x] 怪物显形前后 X/Z 坐标保持一致，不会瞬移到基地、玩家或矿墙前缘。
- [x] 三类怪物正式显形并落地后都会立即进入各自战斗状态，不再原地静止等待整墙坍塌。

## 风险与注意事项

- 直接关闭剪影材质深度测试可能让轮廓穿透矿墙边界和其他场景物体；优先通过墙内实体、局部半透明矿块和正确渲染顺序实现。
- 局部矿块材质不能直接修改共享材质，否则可能让整面矿墙同时透明；需要克隆受影响区域的材质并在清理时释放。
- 剪影阶段不得加入 `enemies` 或 `targets`；只有正式显形并完成落地后才能交接到战斗。
- 强化石怪复用同一个正式实体，激活后最终坍塌回调只能恢复可见性，不能重复加入敌人或目标列表。
- Boss 剪影是独立预览实体，落地后必须只生成一次正式 Boss；最终坍塌不得再次生成。
