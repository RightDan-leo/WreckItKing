# Task: 矿内冻结野怪与分级强度

## 目标

每一段扇形矿墙的墙心都冻着一名守卫。玩家凿隧道时轮廓逐渐显现，凿穿的瞬间守卫破墙而出，正好堵在刚打通的路口。守卫强度随矿墙等级递增，低级墙的守卫弱到不构成威胁。

## 冻结与显形

- 守卫位于所属矿段的中心，即墙体最厚处，**一律面朝主城**（`rotation.y = atan2(-x, -z)`）——也就是玩家凿进来的方向。不转向的话整圈守卫都朝世界 `+Z`，玩家看到的是一排后脑勺。
- 剪影清晰度跟隧道深度走：`penetration` 从 0 到 1，剪影不透明度 `0.34 → 0.74`，眼睛同步放大。
- 凿穿（`penetration ≥ 1`）时切换为正式外观并从地下起身，同时恢复正常深度测试与眼睛原始尺寸。
- 起身即进入战斗，不等待整段矿墙清除。

### 透过矿墙的可读性

矿墙径向 4–5 层、每层不透明度 0.46，叠起来透光率不到一成，**藏在矿墙之后的剪影无论怎么调都看不见**。因此守卫改为压在矿墙之上绘制（`depthTest: false`，`renderOrder` 高于矿层），并遵守以下约束：

- 剪影用**深墨色**而不是浅色。压上去之后底色是高饱和的矿石，深色更能勾出轮廓；浅色会糊成一块白斑。
- 眼睛放大时必须**同步拉开间距**。半径一旦超过间距，两颗眼球会重叠成一个光斑，看不出是一对眼睛。
- 眼睛在冻结状态用**暖白**而不是矿层辉光色。青矿配薄荷绿眼睛等于隐身；暖白在青、紫、橙三种矿色上都压得住。出土后恢复为矿层辉光色。
- X 光绘制必须**按距离收住**（`guardXrayRange`）。不收的话外层守卫会直接画在内层矿墙和主城前面——扇形化后三层墙全在同一个方向上，从城里看是直接叠着的，不收距离会糊成一片。

## 分级强度

| 矿等级 | 守卫定位 | 血量 | 掉金 | 行为 |
|--------|----------|------|------|------|
| 低级 | 教学关 | 3400 | 6 | 只有慢速接触逼近，但它是**唯一一场弓箭之前的仗** |
| 中级 | 常规敌人 | 5800 | 12 | 带地面圆形预警的重砸，命中会击退；另有冲锋 |
| 高级 | 精英 | 13000 | 22 | 扇形 / 跳劈 / 冲锋三招轮换，建议有宠物协同 |

> **2026-09-08 血量整体重排**（850 / 3600 / 9000 → 3400 / 5800 / 13000），低级守卫的
> 伤害同时 3 → 5。原来那一版每场仗只有 1~4 秒，预警、破绽、狂暴（挂在 30% 血线上）
> 全都来不及登场，低级守卫更是「几下即死」——而它偏偏是玩家在拿到弓之前唯一会遇到的怪。
> 推导、台架数据和三局实测见 [power-spike-tuning](power-spike-tuning.spec.md)。

- 三级守卫外观按矿墙等级着色，与矿体颜色一致。
- 所有守卫都沿用现有追击范围与返回原位规则：以出墙位置为领地中心，玩家离开后返回原位等待。
- 身体接触不造成伤害，只有预警结算才判定。
- 守卫死亡额外掉落金币，等级越高掉落越多。

## 龙蛋掉落

- 中级及以上守卫首次死亡时有机会掉落龙蛋。
- 场上同时只允许存在一枚未拾取的龙蛋。
- 玩家已经孵化过宠物后不再掉落。

## 玩家安全

- 低级矿野怪不能把玩家打死，作为教学用的无威胁遭遇。
- 玩家生命值降到低位时停止扣减，改为击退，保证广告体验不会失败。
- 不设置失败结算画面。

## 接口变更

| 模块 | 方法/属性 | 类型 | 说明 |
|------|-----------|------|------|
| Monster | `createOreMonster(tier, position, node)` | 函数 | 按矿墙等级创建守卫，朝向主城 |
| Monster | `ORE_TIERS[tier].monster` | 配置 | 血量、伤害、攻击型态、掉落 |
| Monster | `setMonsterSilhouette(monster, amount)` | 函数 | 按隧道深度更新剪影浓度与眼睛尺寸间距 |
| Monster | `setGuardXray(monster, on)` | 函数 | 切换 X 光绘制与正常深度测试 |
| Monster | `revealOreMonster(node)` | 函数 | 破墙起身，恢复正式材质与眼睛原始形态 |
| Monster | `onOreMonsterDeath(node, monster)` | 函数 | 掉金币、判定龙蛋、推进进度 |
| Config | `CONFIG.guardXrayRange` | 配置 | X 光绘制的距离上限 |

- [x] 每段矿墙都能看到墙心冻结的守卫轮廓。
- [x] 隔着整道矿墙能认出是一对眼睛，而不是一团光斑。
- [x] 守卫出土后恢复正常渲染，不穿透建筑和地形，眼睛回到正常大小。
- [x] 远处矿墙里的守卫不会画到近处的矿墙和主城前面。
- [x] 凿穿后守卫立刻起身开战，堵在刚打通的路口。
- [x] 低级守卫几下即死且打不死玩家。
- [ ] 中级与高级守卫的预警形状可区分且可躲避。

- [ ] 中级以上守卫能掉落龙蛋，且同时只存在一枚。
