# Task: 战力台阶调参

## 需求（用户原话，2026-09-08 11:51）

> 调整一版数值，让玩家没有解锁弓箭时，打怪有点困难，弓箭解锁、每次升级弓箭、孵化出小龙，
> 都能明显感觉到自己变强，打怪效率提升。调整必要的数值参数。

四个要求，可以直接翻成四个可测的量：

| # | 要求 | 量什么 |
|---|---|---|
| 1 | 弓箭之前打怪有点困难 | 第一场仗的时长、挨打次数、掉血 |
| 2 | 弓箭解锁明显变强 | 同一种守卫，拿弓前后的击杀耗时之比 |
| 3 | 每次升级弓箭明显变强 | Lv2 → Lv3 的击杀耗时之比 |
| 4 | 孵化小龙明显变强 | 带不带小龙的击杀耗时之比 |

## 病根：镐头是一把六米长的近战武器

这一版真正的问题不是伤害数字，是**攻击距离**，而它一直伪装成数值问题。

`playerAttackRange()` 返回 `CONFIG.attackRange + WEAPON_LEVELS[等级].reach`，而 `nearestTarget()`
用的闸门是它再 `+ 1.4`（瞄准容差）。Lv1 的 `reach` 原先写 0，于是：

```
弓箭之前的有效交战距离 = 4.8 + 0 + 1.4 = 6.2 米
低级守卫的攻击距离     = 2.4 米
```

**玩家在解锁弓之前就已经在无伤放风筝了。** 实测第一场仗 1.8 秒、掉 3 点血、挨打 1 次——
预警、前摇、破绽、狂暴一套东西一个都没登场（狂暴挂在 30% 血线上，1.8 秒的仗里它闪过去
玩家根本看不见）。

改法是把 Lv1 的 `reach` 改成 **-3.0**，让镐头变成真近战（1.8 + 1.4 = 3.2 米）。
放在武器表里而不是改 `CONFIG.attackRange`，是因为 `reach` 整个挂在 `weaponEnabled()` 下面：
`?arpg=0` 的回滚路径读不到它，照旧是 4.8，一格不动。

改完之后三层守卫和玩家的距离关系变成：

| | 守卫攻击距离 | Lv1 玩家（3.2） | Lv2/Lv3 玩家（6.8） |
|---|---|---|---|
| 低级 | 2.4 | 够得着玩家 | 够不着 |
| 中级 | 3.0 | 基本持平 | 够不着 |
| 高级 | 3.7 | **反过来压着玩家打** | 够不着 |

弓在 Lv2 给的那 6.8 米因此才成为一次能当场感觉到的变化——不是「伤害数字变大了」，
是「我不用再站在它爪子底下了」。

## 量法：先修台架，再调数值

一开始拿完整自动局的数据调，调不动：同一档的实测 eDPS 能从 567 飘到 3725，飘的全是
交战质量（有没有在躲、被击退推出去几次、路上跑了多久），不是战力。

所以加了 `__wik.duel(tier, { weapon, pet })` 这个台架，把变量锁死：指定战力、把守卫复位成
满血、玩家只做「够不着就走过去，够得着就站定」。同一组数值跑三遍结果一致（3.77 / 3.35 / 3.35，
第一遍差是因为守卫还没出土）。

> 台架踩过一个坑，写下来：**复位要连位置和位移状态一起清**。只清血量的话，上一场把守卫
> 冲锋出去七米、或者钉在拴绳边界上的那个位置会带进下一场，于是同一组数值能测出 10.35 秒
> 和「90 秒打不完」两种结果。现在 `homePosition`、`dash`、`knockback`、`detour`、`closeFail`
> 一起复位。

台架测的是**输出上限**，不是真实体感——它不躲、不风筝。真实体感照旧由完整自动局给，
两个数一起看才有意义。

## 落地的数值

| 项 | 原值 | 新值 | 为什么 |
|---|---|---|---|
| `WEAPON_LEVELS[0].reach` | 0 | **-3.0** | 镐头变近战，见上一节 |
| `ORE_TIERS.low.monster.hp` | 850 | **3400** | 唯一一场弓箭之前的仗，要撑到五六个前摇回合 |
| `ORE_TIERS.low.monster.damage` | 3 | **5** | 3 点在一百格的血条上是一根头发丝 |
| `ORE_TIERS.mid.monster.hp` | 3600 | **5800** | 砸地和冲锋两招至少各来一轮 |
| `ORE_TIERS.high.monster.hp` | 9000 | **13000** | 三招轮换要轮得满一圈 |
| `BALANCE.pet.hatched` | 180 / 0.85s | **520 / 0.45s** | 212 → 1156 DPS |
| `BALANCE.pet.evolved` | 620 / 0.42s | **1150 / 0.30s** | 1476 → 3833 DPS |
| `CONFIG.playerMaxHp` | 100 | **130** | 一整局的挨打预算 |
| `ECON.weaponCost[1]` | 6 | **12** | 把小龙和 Lv3 这两次变强拆开，见下 |

玩家伤害（235 / 425 / 805）**一个数都没动**。要的是台阶更陡，而台阶是由「打多久」构成的，
不是由伤害数字构成的——动血量能一层一层分开调，动伤害是一根杠杆撬全场。

### 血量抬多少不是线性的

低级守卫中间量过 2200，只有 3.7 秒。血量抬上去 TTK 不是线性涨的：仗越长，三连击第三下
落满的次数越多，平均 DPS 反而从 395 升到 595。所以要多加一截才买得到那几秒。

### 挨打预算：为什么抬血量上限而不是压守卫伤害

血量只降不升、下限 15（见 `damagePlayer`），所以 `playerMaxHp - playerMinHp` 就是
**一整局的挨打预算**。战斗调硬之后 85 点这份预算在第 53 秒就见底了：血条从那儿起一路
钉在下限上，剩下 60% 的流程里挨不挨打对它毫无影响，等于把这根条废掉。

抬上限而不是压守卫伤害：伤害压下去，第一场那记「打怪是要付代价的」就也一起没了，
而那正是这一版要立起来的东西。130 之后见底时间推到 98 秒（全程的 71%）。

### 低级守卫伤害为什么只抬到 5 不抬到 7

中间试过 7，实测第一场就掉 57 点：吃掉三分之二预算，而且开局十五秒内把血条打到见底，
在 playable 里读起来像「我要输了」。5 之后是 39~51 点，血条掉到六成，读作「这仗不轻松」。

### 小龙那一档为什么要动价格

这一条是数值调不出来的，只能动顺序。

`weaponCost` 是 6 的时候实测破壳在 92.0 秒、弓 Lv3 在 94.7 秒——中间隔 2.7 秒，而且
**中间没有任何一场仗**：玩家手上的钻石在孵化那一刻就够买 Lv3 了，于是这两次变强在体感上
糊成一次，需求里的第 4 条根本没有被观测的机会。

抬到 12 之后，他得先用「只带小龙、武器还是 Lv2」的状态打赢一只高级守卫，小龙那份贡献
才有地方被看见。钻石账随之变成 供给 44 / 支出 4+12+8+14=38 / 余 6（原先余 12，
`weaponCost` 上面那条「余 12 颗要想办法吸收」的待办一并解决）。

这一步不会造成死锁：`ensureProgressAffordable` 的兜底只在「没矿可挖、且没怪能掉这种货币」
时才发钱，而武器台在钻石单轨里是可见的，已经在兜底名单内（见 progression-ladder-rework）。

### 小龙为什么优先压间隔而不是加单发

先试过 460 / 0.62 秒（742 DPS），高级守卫那场只快了 15%，中级那场**一点没快**。
原因是火球有飞行时间，而一场两三秒的仗里小龙只来得及打两三发，单发再大也有一发落在
怪已经死了之后。改成 520 / 0.45 秒（同量级 DPS，包更小更密）之后高级那场快了 28%。
顺带也更像「有个东西在替你打」——单发大只是偶尔闪一下。

### 对着四条需求验收

- [x] **弓箭之前有点困难**：8.0 秒、掉 51 点（血条四成）、五六个前摇回合。原先 1.8 秒掉 3 点。
- [x] **弓箭解锁明显变强**：同一种守卫 8.0s → 2.7s（快 3 倍），掉血 51 → 5。全场最大的一次跃升。
- [x] **升级弓箭明显变强**：高级守卫 6.6s → 5.1s，掉血 24 → 0；台架口径中级 4.37 → 2.28（快 1.9 倍）。
- [x] **孵化小龙明显变强**：high-0 那场是专门为它腾出来的——Lv2 带小龙 6.6 秒，
      而台架里 Lv2 不带小龙打同一只是 12.52 秒。

## 已知的取舍

**`?arpg=0` 不再是「平衡上」干净的回滚。** 守卫血量不在 ARPG 开关下面（建场时从 `ORE_TIERS`
烘进对象），所以回滚路径也吃这份新血量，而那条路径的伤害上限只有 805（锄头驱动）。
实测它仍然能跑完（113.5 秒走到 CTA、零报错、`reach` 正确退回 4.8），**代码路径是干净的**，
只是打起来比改动前慢。这个开关的用途是验「ARPG 那套行为有没有漏判 enabled」，那个用途
不受影响；它从来不是一份可发布的平衡配置。

**血条仍然会在 98 秒左右见底。** 抬到 130 只是把它从 53 秒推到 98 秒，没有根治——
根治要么给回血，要么让血量能致死，两件都超出这次的范围，也都和「playable 不能让人失败」
这条底线冲突。

## 顺带清掉的

- 调参面板里武器 **Lv4** 的三行死配置（`weaponCost.2`、`WEAPON_LEVELS.3.splash` /
  `.splashRatio`）——武器线在 2026-09-07 就砍到三级了，那几行读出来是 `undefined`。
- 补了 `WEAPON_LEVELS.0/2.reach`、`CONFIG.playerMaxHp` / `playerMinHp` 四根滑块。
  Lv1 的 `reach` 现在是「弓箭之前有多难」的主旋钮，没有滑块调不动。
- 武器线那组的 `note` 里钻石账是旧的（写着「武器 18 = 40，余 4」），改成 16 / 38 / 余 6。
