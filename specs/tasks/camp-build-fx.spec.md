# Task: 营地建筑出现 / 升级特效

## 背景与动机

参考视频里，营地不是瞬间替换，而是「地块闪白 → 地板格子亮起 → 墙体白模弹起 → 贴图落稳 → 边沿高光」。现有 `buildCamp(stage)` 会整组删掉重建，只补一圈金色火花，建筑反馈偏硬。

本任务只补建筑出现与升级的视觉，不改流程、费用和阶段顺序。

## 目标

玩家踩地块付完金币后，能在约 0.6–0.9 秒内看到与参考视频同结构的四段反馈：地块白闪、地板格子白光、构件白模弹性升起、落稳后的边沿高光。升级 / 扩建时旧建筑保留，只让新增构件走同一套动画。

## 2026-08-26 修订：轻量分层扩张方案

第一版逐 Mesh 创建材质、地板和重复营地组，触发时出现明显卡顿，且误改了通用升级框。本节覆盖下方第一版技术方案：

- 完整恢复原有圆形升级框、世界空间名称和费用显示；建筑特效不得改动 `createZone` 的视觉结构。
- 营地在初始化阶段预创建，不在支付完成瞬间创建几何体或材质。
- 地板拆成核心地板、Stage 2 外扩环、Stage 3 外扩环；外扩环分别保持隐藏。
- 围墙拆成三圈，每圈再按四边组成动画组；同一时刻只保留当前圈和过渡中的下一圈。
- 初建：核心地板显现，第一圈围墙从地下弹起。
- 强化：基地从 `8.5 × 8` 小幅扩到 `10.2 × 9`，同时强化设施与武器。
- 安放龙蛋时再次扩张到 `12 × 10`：新增地板环发光展开，旧围墙下沉，外圈新围墙弹性升起；已有核心地板和设施保持不动。
- 白光使用预创建、共享的叠加材质或单张格线平面，不为每个构件创建独立材质。
- 触发时允许创建少量动画状态对象，但不得创建 WebGL Geometry、Material、Texture 或完整营地副本。
- 单次扩张活跃动画组目标不超过 10 个。

## 视觉规格

### 1. 地块

- 贴地正方形，边长约 2.2，略高于地面。
- 默认：深色底 + 虚线白边 + 白色图标 + `金币 + 费用`。
- 金币 > 0：底变绿，边更亮。
- 付费中：可选一条贴地绿进度条，按 `paid / cost` 增长。
- 付完：图标和费用立刻消失，整格闪成实心白，约 0.12s 后淡出，交给地板格子。

图标：建营房屋、强化锤子、孵化蛋。可用 Canvas 贴图或简单几何拼，不必贴正式美术。

### 2. 地板格子白光

- 营地占地按约 2.0 的格子切。
- 每格一张贴地白平面，`MeshBasicMaterial`，透明，可叠加。
- 从付费点或营地中心向外错开点亮，单格亮 0.18–0.28s 后淡到石板。
- 扩建只亮新增面积，旧地板不重闪。

### 3. 构件白模 + 弹性升起

对墙、门、工作台、壁炉、火把、孵化台分别处理：

1. 起始：`y` 低于最终位置约 0.8–1.4，`scale.y` 约 0.15。
2. 升起：0.28–0.42s，`easeOutBack`（过冲约 1.18），到顶后轻微回落。
3. 白模：升起期间用 `MeshBasicMaterial` 纯白，或把 Standard 的 emissive 拉满。
4. 回材质：到达后 0.16–0.24s 从白淡回原材质。
5. 错开：按到付费点 / 中心的距离，每件延迟 0.03–0.06s。整段 0.55–0.85s 内结束。

旧营地下一阶段不要删掉重刷。修订方案使用预创建的分层营地，只切换和动画对应地板环、围墙圈及新增设施。

### 4. 升级高光

- 墙根一圈暖白内沿光，约 0.6s 淡到很弱常驻，或完全淡出。
- 完成瞬间在落点出黄白星芒（十字芒 + 短火花），比现在的 `buildPopEffect` 更锐。
- 装备升级：工作台武器 emissive 拉高再回落，并出一小波火花。
- 角色 LEVEL UP 大字和全身闪光：本任务可选。默认先做营地，不做角色升级字。

## 风险与注意事项

- 增量扩建比整组重建难，但能避免旧墙闪没。碰撞体必须在动画开始时就按最终尺寸生效，避免玩家穿墙。
- 不要上 `EffectComposer` / Bloom。白光用 `MeshBasicMaterial` 和透明叠加即可。
- 动画进行中若玩家已走向下一矿层，不要锁移动。
- 诱饵地块（结尾 CTA）只播地块反馈，不要真的改建营地。
