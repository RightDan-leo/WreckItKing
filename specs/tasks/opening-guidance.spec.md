# Task: 开局前进与自动挖矿引导强化

## 背景与动机

当前开场教程只用原地手势说明“可以拖动”，首次输入后立即消失；场地虽然已有通道碰撞，但边缘缺少对应模型。玩家可能不知道应向前接近晶矿，也可能碰到不可见边界。

## 目标

在不增加地面箭头、不改变主流程和操作方式的前提下，通过可见场地漏斗、定向滑动手势和首矿呼吸高亮，让玩家明确理解“向前移动，靠近晶矿会自动挖掘”。

### 受影响模块

|------|------|----------|----------|----------|

| 开场教程 UI | 本文件 | `WreckItKing.html` 教程 CSS / DOM / 输入逻辑 | 修改 | 手势改为单向上滑，替换教学文案，并延后隐藏时机 |

## 视觉与交互规格

### 场地漏斗

- 开局区域现有可行走半宽保持 `4.1`，不额外缩窄。
- 左右边界用现有紫色晶簇和石块形成连续但不整齐的视觉围挡。
- 角色后方增加低矮碎晶，解释后方世界边界，但不得遮挡角色。
- 所有模型放在现有碰撞边界外侧，视觉边缘与实际碰撞保持一致。
- 中央前进路线和首矿金币保持无遮挡。

### 手势与文案

- 文案使用「向前拖动，靠近晶矿自动挖掘」。
- 手势只沿屏幕纵向向上滑动，不再左右摆动。
- 首次输入不关闭教程。
- 玩家从出生点向首矿方向前进约一个角色身位后，手势淡出。
- 只横向移动或向后移动时，手势不消失。
- 首矿尚未命中且玩家停住约 2 秒时，手势重新出现。

### 首矿高亮

- 第一层矿墙在首次有效命中前做轻微呼吸高亮。
- 只调整矿墙现有材质的 emissive / 亮度，不缩放矿墙，不新增中央光点。
- 墙上金币保持现有效果，不增加浮动动画。
- 第一次有效挖矿命中后停止呼吸，并关闭底部开场教程。

- [x] 增加独立开局引导状态，按向前位移、静止时间和首次命中控制显隐
- [x] 为首矿增加不缩放模型的轻微材质呼吸，并在首次有效命中后恢复
- [x] 验证开局引导、移动、自动挖矿及后续流程未受影响

## 验收标准

- [x] 首屏左右和后方边界有可见晶簇/岩石，中央路线清晰且无遮挡
- [x] 玩家不能看到与现有碰撞明显不一致的空气墙
- [x] 手势明确向矿墙方向上滑，文案为「向前拖动，靠近晶矿自动挖掘」
- [x] 首次触摸或按键不会立刻隐藏教程
- [x] 向前移动约一个角色身位后手势淡出，横移或后退不会误触发
- [x] 首矿未命中且玩家静止约 2 秒时手势会重新出现
- [x] 首矿只做材质呼吸，不增强中央光点，不让墙上金币新增浮动
- [x] 首次有效挖矿命中后教程和呼吸高亮结束
- [x] 四层矿、营地、龙蛋、Boss 与 CTA 流程保持不变
- [x] 浏览器无新增运行时错误，移动端竖屏和桌面键盘均可完成开场

## 风险与注意事项

- 边界装饰不可进入中央攻击路线，也不能遮挡首矿金币。
- 首矿材质可能被多个 Mesh 共享；动画时必须保存并恢复原始 emissive，避免影响后续矿墙。
- 手势重提示只在首矿首次命中前生效，不能在后续阶段再次出现。
- 不新增地面箭头、自动移动、镜头锁定或强制输入。
